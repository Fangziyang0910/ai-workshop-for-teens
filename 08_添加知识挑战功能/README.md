# 第8课 添加知识挑战功能

[项目首页](../README.md) · [课程资料目录](../00_课程大纲与资料/README.md) · [上一课：建立展品知识库](../07_建立展品知识库/README.md) · [下一课：试用并改进讲解助手](../09_试用并改进讲解助手/README.md)

## 一、本课定位

语言项目第3课：加入明确的任务选择，形成讲解与挑战两条路径，保存语言V3。

面向零基础初中生；每班约30人、8组，每组3～4人；每次90～120分钟。

| 项目 | 本课安排 |
|---|---|
| 核心问题 | 怎样让参观者既能听讲解，也能参与知识挑战？ |
| 重点讲解 | 输入选项、条件判断、执行路径与输出检查。基础版由用户选择任务。 |
| 学生实操 | 编辑两条分支，生成一道有依据的两选一题，完成八次路径测试。 |

## 三、课前准备

**硬件与物品：**每组一台电脑、浏览器、小组账号、第7课知识库及纸面流程图用纸。

**软件与文件：**Dify课程平台；沿用本组知识库。入口选择任务`task`和展品`topic`，每次只执行一条生成分支。

1. 保留语言V2，导入第8课模板并确认两条路径都能执行。
2. 准备任务与展品选项，示范更改选项后新建会话。
3. 挑战题应包含题干、两个选项、答案、解释及资料编号。基础版同条回复提供答案，不含自动评分或成绩存储。

## 四、课堂安排

按以下顺序组织课堂；各环节时长以本课完整教学设计为准。

1. 体验讲解与挑战，画出入口、条件、两项任务和出口。
2. 查看`task`和`topic`，沿执行记录确认选择怎样影响路径与检索。
3. 轮流修改讲解要求、挑战格式和依据规则，保证只有一个正确选项。
4. 完成八次测试，分别记录路径是否正确、内容是否有资料依据。
5. 邻组体验题目，先作答再核对；修订一处问题并复测。
6. 保存语言V3、流程图和测试记录。

## 五、成果检查

- [ ] 两种任务均能按所选路径执行，每人能解释一个节点或规则。
- [ ] 挑战题答案与解释一致，有资料依据；题目格式完整。
- [ ] 任务选择与文字要求冲突时，以任务选择为准，并提示切换。

## 六、课后衔接

**课后任务：**请一人体验讲解和挑战，记录一处停顿或不清楚的地方。可在副本探索自动判断任务，保留基础版。

**下次课准备：**语言V3、原始输入与输出、流程图及体验反馈。

课后基础任务约30～60分钟。没有家庭电脑时，先整理材料与记录，再到学校开放机房操作。
