# 第8课 添加知识挑战功能

本课面向零基础初中生，每班约30人，分为8组，课时为90～120分钟。

## 教学目标

学生能够根据“了解内容”和“参与挑战”两种需求画出流程，设置明确的任务选择，分别编辑两条路径并检验。学生应能解释：参观者选择任务后，程序怎样进入对应分支。

## 成果与评价

提交讲解与挑战两条分支讲解助手、流程图和八次测试。每名学生能说明一个节点或规则的作用。教师检查两种任务是否按选择执行，以及输出是否有资料依据。自动意图识别不列入基础评价。
