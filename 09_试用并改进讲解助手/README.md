# 第9课 试用并改进讲解助手

[项目首页](../README.md) · [课程资料目录](../00_课程大纲与资料/README.md) · [上一课：添加知识挑战功能](../08_添加知识挑战功能/README.md) · [下一课：校园AI创客展](../10_校园AI创客展/README.md)

## 一、本课定位

语言项目第4课：完成试用、修改与复测，整理两个项目的展示档案。

面向零基础初中生；每班约30人、8组，每组3～4人；每次90～120分钟。

| 项目 | 本课安排 |
|---|---|
| 核心问题 | 别人怎样使用我们的作品，最应先解决哪个问题？ |
| 重点讲解 | 用户观察、问题优先级、修改前后证据，以及修复后的复测。 |
| 学生实操 | 交换试用，完成十五题测试，修复一个主要问题并检查原有功能。 |

## 三、课前准备

**硬件与物品：**每组一台电脑、浏览器、小组账号、语言V3备份及视觉项目档案。

**软件与文件：**Dify课程平台及本组已有应用；视觉项目只检查文件恢复，不在本课重新制作。

1. 安排相邻组互为使用者，准备简短操作说明和十五题问题表。
2. 保存语言V3副本与当前资料原文，确认账号可用。
3. 列出六项试用任务：选择展品、请求讲解、追问事实、知识挑战、缺资料问题、结束。

## 四、课堂安排

按以下顺序组织课堂；各环节时长以本课完整教学设计为准。

1. 交换工位，请使用者独立完成六项任务；设计者记录停顿、误选和错误回答。
2. 对照十五题补齐遗漏，保留实际输入与输出。
3. 优先处理事实错误、任务失败和入口不清，选择一项主要问题修改。
4. 复测失败题，再抽查原先正确的题目，记录改善或未改善的结果。
5. 完成一页作品说明和一分钟演示，安排第10课展示分工。
6. 导出语言应用、保存资料和测试，核对视觉档案，教师集中备份。

## 五、成果检查

- [ ] 有试用记录和至少一项修改前后证据，观察者没有代替用户操作。
- [ ] 资料、应用配置与说明属于同一版本，事实和性能介绍有实际依据。
- [ ] 每人能说明自己的具体工作，两个项目文件均可找到。

## 六、课后衔接

**课后任务：**排练三分钟展示，每人承担一段；录制1～2分钟连续演示作为备用。可制作一页海报。

**下次课准备：**稳定版工程与模型、应用与资料、设备、作品说明、测试记录、视频及分工。

课后基础任务约30～60分钟。没有家庭电脑时，先整理材料与记录，再到学校开放机房操作。
