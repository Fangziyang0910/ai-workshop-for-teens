# 第9课 试用并改进讲解助手

本课面向零基础初中生，每班约30人，分为8组，课时为90～120分钟。

## 教学目标

学生能够观察真实使用过程，按影响程度选择问题，完成一次修改与复测。重点是把作品交给不熟悉它的人，用事实判断是否好用。本课主要时间用于试用、修改和复测，文件整理与展示排练安排在最后。

## 成果与评价

完成语言作品、用户观察、一次改进前后证据和两个项目档案。每名学生说明一项自己的实际工作。教师评价修改与问题是否对应，以及最终介绍是否符合实际表现。
