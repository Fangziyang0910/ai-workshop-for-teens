## 一、本课定位

视觉项目第4课：完成桌面物品识别提示器，并为语言项目整理作品事实。

面向零基础初中生；每班约30人、8组，每组3～4人；每次90～120分钟。

| 项目 | 本课安排 |
|---|---|
| 核心问题 | 别人能否按说明独立使用我们的作品？ |
| 重点讲解 | 使用对象、操作说明、结构与输入条件，以及基于试用的修改。 |
| 学生实操 | 固定装置、编写说明、完成六项用户任务测试，保存视觉项目档案。 |

## 三、课前准备

**硬件与物品：**每组带齐视觉装置、电脑、摄像头、开发板和文件；另备纸板、固定夹、胶带、标识纸及剪刀。

**软件与文件：**Mind+及本组稳定版工程和模型。保持既有类别与用途，优先修复影响使用的问题。

1. 把相邻两组配成试用搭档，提前分发结构材料和记录表。
2. 从关闭状态启动一次作品，确认模型路径、取景区和图案方向。
3. 教师准备录像设备，要求演示包含实际输入与输出。

## 四、课堂安排

按以下顺序组织课堂；各环节时长以本课完整教学设计为准。

1. 用一句话说清作品帮助谁做什么，选一个最影响使用的问题。
2. 固定摄像头和开发板，标出摆放区与归位区，避免装饰遮挡镜头。
3. 写启动、摆放、反馈、停止四步说明，明确需要电脑。
4. 邻组完成六项用户任务，设计者先观察，再修复一个主要问题并复测。
5. 完成一分钟演示，归档工程、模型、原图、测试、说明和视频。
6. 把作品整理为用途、组成、规则、使用范围四条事实，带入第6课。

## 五、成果检查

- [ ] 另一组能按说明启动和使用；能理解三类图案及暂停方式。
- [ ] 结构和取景条件明确，作品说明与实际能力相符。
- [ ] 每人解释一项实际工作；文件完整，四条作品事实有依据。

## 六、课后衔接

**课后任务：**请家人或同学试用，记录一句反馈，补齐四条作品事实。可完善系统图或标识。

**下次课准备：**视觉项目档案和四条短资料；第6课使用课程账号，不要求学生申请模型服务。

课后基础任务约30～60分钟。没有家庭电脑时，先整理材料与记录，再到学校开放机房操作。
