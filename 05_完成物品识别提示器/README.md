# 第5课 完成物品识别提示器

本课面向零基础初中生，每班约30人，分为8组，课时为90～120分钟。

## 教学目标

学生能够将分类、提示和结构组织成别人可以使用的作品，完成说明、交换试用和一次针对性的修改。学生围绕第2课确定的用途完成结构和说明，自主选择主题与外观。

## 成果与评价

完成视觉作品和一页说明，另一组能够按说明启动并使用。教师检查每名学生实际参与、作品范围与测试是否一致。简单结构可以获得较高评价，前提是用途明确、解释清楚、文件完整。
