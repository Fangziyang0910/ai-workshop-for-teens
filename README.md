# AI 创想工坊

面向中学生的 AI 实践课程。课程共 10 次，每次约 2 小时，围绕“AI 智能伙伴”项目，逐步学习机器学习、micro:bit、生成式 AI、知识库和 Agent。

本仓库用于持续整理课程大纲、教师教案、授课课件和学生活动材料。目前已收录第一课的配套材料，第 2～10 课预留独立目录，随备课逐步补充。

## 课程大纲与资料

- [课程大纲与设备采购](00_课程大纲与资料/课程大纲与设备采购.md)：课程目标、十次课的安排、课堂组织、硬件采购和项目评价。
- [教学平台与参考资源](00_课程大纲与资料/教学平台与参考资源.md)：学生使用的平台和教师参考资源。
- [图片素材](00_课程大纲与资料/图片素材/)：课程共用的图片和标志素材。
