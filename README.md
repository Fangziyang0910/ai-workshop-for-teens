# AI创想工坊

面向零基础初中生的人工智能实践课程。学生通过两项连续项目，学习采集数据、使用模型、连接硬件、核对结果和改进作品。每课都有动手任务，课间一个月用于自主实践。

| 项目 | 课程安排 |
|---|---|
| 授课对象 | 初中生，默认无编程基础 |
| 课次与时长 | 共10次，每月一次，每次90～120分钟 |
| 班级与分组 | 两班同时授课，每班约30人、8组，共16组，每组3～4人 |
| 学习设备 | 每组一套设备，按组编号、长期保管与轮用；使用学校现有Windows电脑 |
| 课程结构 | 第1课入门，第2～5课视觉项目，第6～9课语言项目，第10课展示 |
| 结课作品 | 桌面物品识别提示器、校园展览讲解助手，以及制作、测试和改进记录 |

- **课堂文件：**已有三份Mind+起始工程、三个Dify模板、展品资料、提示词、测试表和十课任务卡，见[课堂配套材料](00_课程大纲与资料/配套材料/README.md)。
- **授课课件：**第1课提供独立教师教案、PPTX、预览PDF、学生活动PDF、离线手写数字分类器、贪吃蛇提示词与备用游戏。第2～10课当前使用分课教学设计、操作手册和任务卡组织课堂，未另列独立PPTX或活动PDF。
- **软件与官方资料：**安装包、离线依赖、服务器镜像和官方教程已在本地整理，位置与用法见[本地资源目录](00_课程大纲与资料/本地资源/README.md)。

教学文件分开保存：课件供投屏，教案供教师组织课堂，任务卡和记录表供学生操作。教师发放材料前，先选出当课内容；测试题的参考判断留作教师核对。

## 四、设备与运行条件

视觉项目使用Windows电脑、Mind+、C270摄像头和micro:bit V2。图像分类在电脑运行，开发板显示提示，不需要学生购买GPU算力。语言项目通过浏览器访问学校课程平台，由教师统一管理Dify、模型服务与账号。

学校准备18台现有电脑：16台学生工位、2台教师工位。16套学生设备另配2套开发板和摄像头公共设备，兼作教师演示与备用。器材及在线服务预算合计13,500元，属于预算额度；明细见[设备与经费安排](00_课程大纲与资料/课程实施方案与分课教学设计.md#十六设备配置与经费安排)。

软件版本、安装步骤与设备型号以[设备软件配置与教学资源](00_课程大纲与资料/设备软件配置与教学资源.md)和[本地资源目录](00_课程大纲与资料/本地资源/README.md)为准。课堂不依赖境外教学网站；语言项目需要访问课程服务器及国内模型服务。第一课的数字分类器与备用游戏可离线运行，视频已内嵌；现场用DeepSeek生成游戏时，需要教师账号和网络。

## 五、文件保存与资源管理

GitHub保存教案、课件、工程、模板、资源清单、校验值和恢复脚本。大型第三方安装包、官方网页缓存和服务器镜像保存在`00_课程大纲与资料/本地资源/下载文件/`，不在Git提交中。只克隆仓库不会取得这些下载文件；首次转移到学校时复制完整本地课程目录，或按本地资源指引恢复下载。

课程共用文件集中在`00_课程大纲与资料`；各课目录保存本课教案、课件和活动材料。第一课的视频与图片按类型放在`授课课件/素材/`，供修改课件使用；授课直接使用PPTX，预览使用PDF，打印使用学生活动PDF。

学生作品按组号保存，视觉项目与语言项目分别记录版本。每次课后保留原始输入、实际结果及改动记录，由另一位成员检查恢复。账号密码、API Key、服务端备份和学生个人数据不提交到公开仓库。
