# AI创想工坊

面向初中零基础学生的人工智能实践课程。两个班同时授课，每班约 30 人、8 个小组，共 16 组，每组一套设备。课程共 10 次，每月一次，每次 90～120 分钟。

课程按“人工智能入门—视觉识别项目—自然语言项目—成果展示”组织，配套课内实践与课后自主探索。

完整资料入口：[课程资料目录](00_课程大纲与资料/README.md)，包含十课教学设计、两个项目操作手册、学生任务及课堂模板。
