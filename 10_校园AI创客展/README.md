# 第10课 校园AI创客展

本课面向零基础初中生，每班约30人，分为8组，课时为90～120分钟。

## 教学目标

学生能够面向他人清楚介绍作品、进行现场演示、回答关于输入输出和测试改进的问题，并通过参观同伴作品总结学习经验。学生应结合实际操作和测试记录，说明作品怎样工作、自己做了什么改进。

## 成果与评价

每组提交最终成果档案和同伴反馈，每人提交个人总结。评价结合全过程记录，不只看最后五分钟表现。网络或设备临时故障时，可以使用事先录制的真实演示视频说明作品，并明确现场未完成的部分；对学生的概念理解与实际参与仍可进行评价。
