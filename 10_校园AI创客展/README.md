# 第10课 校园AI创客展

[项目首页](../README.md) · [课程资料目录](../00_课程大纲与资料/README.md) · [上一课：试用并改进讲解助手](../09_试用并改进讲解助手/README.md)

## 一、本课定位

课程收尾：展示两项作品、解释制作与改进过程，完成个人总结和归档。

面向零基础初中生；每班约30人、8组，每组3～4人；每次90～120分钟。

| 项目 | 本课安排 |
|---|---|
| 核心问题 | 怎样让别人理解作品，也理解我们做过的工作？ |
| 重点讲解 | 依据实物与记录解释系统，准确说明学生、教师和现成工具分别完成了什么。 |
| 学生实操 | 布展、三分钟展示、两分钟问答、轮换体验、个人总结和设备交接。 |

## 三、课前准备

**硬件与物品：**每组一张作品台、一台电脑、所需摄像头和micro:bit V2、数据线、作品说明、组号及备用视频；教师使用投影设备。

**软件与文件：**已保存的Mind+工程与模型、Dify课程应用和浏览器。本课使用稳定版本。

1. 两班分别组织，每班8组；每组3分钟展示、2分钟问答，共40分钟。合场展示须另行增加时间。
2. 现场检查启动、模型或资料加载、网络、备用视频和成员分工。
3. 每组重点演示一项作品，另一项用短视频或简要说明呈现；两项档案均需保留。

## 四、课堂安排

按以下顺序组织课堂；各环节时长以本课完整教学设计为准。

1. 按清单布展并启动作品，确认备用视频能播放。
2. 依次展示用途、核心功能、一次改进与成员工作，回答具体问题。
3. 轮换值守与参观，每人参观至少两组、实际体验至少一项作品，给出具体反馈。
4. 结合第一课记录完成个人总结，解释一次失败与认识变化。
5. 归档两项作品及反馈，核对设备和后续保管人；有意继续者选择一个明确问题。

## 五、成果检查

- [ ] 每组提交两项作品档案与同伴反馈，每人提交个人总结。
- [ ] 演示与说明符合实际能力；概念理解、动手参与和改进证据共同纳入评价。
- [ ] 设备或网络故障时使用真实备用视频，说明现场未完成的部分，继续检查学生理解。

## 六、课后衔接

**课后任务：**有兴趣的小组继续解决一个真实问题。参赛前按具体赛事核对年龄、队伍人数、作品类别和提交要求。

**归档要求：**课程结束后保留工程、模型、资料、DSL、测试、说明、视频和个人总结；明确设备与文件的保管安排。
