# 第1课 AI侦探

[项目首页](../README.md) · [课程资料目录](../00_课程大纲与资料/README.md) · [下一课：训练自己的物品分类器](../02_训练自己的物品分类器/README.md)

## 一、本课定位

课程入门：通过案例、分类测试、程序比较和资料核对，认识AI的能力与使用方法，并了解后续两项作品。

面向零基础初中生；每班约30人、8组，每组3～4人。建议120分钟，也可按教师教案压缩为90分钟。

| 项目 | 本课安排 |
|---|---|
| 核心问题 | AI可以做什么，我们怎样检查它的结果？ |
| 重点讲解 | 输入与输出、模型的学习与使用、模型与程序的分工、回答的事实依据 |
| 学生实操 | 分类案例卡、测试手写数字识别、观看DeepSeek制作与修改贪吃蛇、核对回答 |

## 三、课前准备

**硬件与物品：**每组一台电脑、鼠标及打印材料；教师准备投影和声音播放设备。本课不需要摄像头或开发板。

**软件与文件：**Chrome或Edge、授课PPTX、课堂演示目录、学生活动PDF。数字分类器与备用游戏可离线使用；DeepSeek现场生成需要教师账号与网络。PDF不播放视频，视频演示使用PPTX。

1. 打开课堂演示入口，手写一个数字并点击识别；再载入真实样例。模型已经内置，不需要另行采样或训练。
2. 按教师教案打印案例卡、分类底板、测试记录和课末记录，分组放好。
3. 在授课电脑检查课件、内嵌视频、声音、数字识别与贪吃蛇。展示优先使用课件内嵌视频与本地文件；外部链接供延伸查阅，不在课堂等待在线入口加载。

开场案例涵盖交互工具、游戏生成、展馆交流、古诗短片、三维设计与软件操作。经典神经网络动画用于原理说明。具体素材、播放方式和页码以课件与活动对应表及教师教案为准。

## 四、课堂安排

按以下顺序组织课堂；时间与提问以教师教案为准。

1. 观看能力案例，说出各自接收什么信息、产生什么结果，再了解十课的两项作品。
2. 根据卡片描述的具体做法分类，每人解释至少一张卡片的依据。
3. 区分模型的学习与使用，轮流测试数字分类器：先预测，改变一种写法或一段笔画，再记录结果。
4. 由教师向DeepSeek发送贪吃蛇要求，运行后再要求速度减半。比较实际效果，并检查计分、暂停与重开。网络或生成不顺时使用备用成品或课件录像。
5. 对照社团资料核对回答中的时间与费用，说明哪里有依据、哪里需要再查。
6. 写下自己的工具想法和检查方法，完成课末记录。

## 五、成果检查

- [ ] 每人参与案例判断或实际测试，并能解释一个输入、处理与输出的例子。
- [ ] 分类测试保留真实结果，能说明改变了哪个条件。
- [ ] 能指出程序修改后的变化，并对照资料核实“50元材料费”的说法。
- [ ] 每人留下作品想法，写清帮助谁、做什么、准备怎样检查。

## 六、课后衔接

**课后任务：**观察一个熟悉的AI功能，记录输入、结果及一条需要核实的信息。可比较固定时间提醒与社团问答分别适合用什么工具。

**下次课准备：**两类清洁、轻便、便于拍摄的物品，统一示例为胶棒和橡皮。学生不需要注册新平台。

课后基础任务约30～60分钟。没有家庭电脑时，先完成观察、记录与物品准备。
