# 第一课 AI侦探

本课面向零基础初中生，结合科普讲解、近期官方演示、小组讨论和实际测试。建议120分钟，也可按教师教案压缩为90分钟。

学生先了解AI的不同能力和十次课的制作任务，再根据案例说明判断哪里使用了AI。随后区分模型的学习与使用，测试分类器，比较程序修改前后的效果。最后核对一段回答的依据，并记录自己的作品想法。

## 课件与活动衔接

[课件与活动对应表](授课课件/第一课_AI侦探_课件与活动对应表.md)说明各页的教学用途、前后关系及对应材料。每页演讲者备注提供讲解、提问和来源。

开场包含OpenAI交互式讲解、Kimi可交互游戏、SeedRealtime展馆交流、Seedance古诗短片、Qwen三维设计和OpenAI软件操作六个官方案例。经典神经网络动画单独用于原理解释。

四段国内模型展示和一段原理动画已内嵌。OpenAI案例和视频使用官方在线入口。课件中的视频页保留静态封面，PDF不播放视频。

## 课前准备

教师提前在各组电脑上打开分类器，备好笔、橡皮、另一件同类物品及深浅两种背景。按教案数量打印案例卡、分类底板、测试记录和课末记录。课前在授课电脑上检查课件、声音、在线入口和摄像头。

程序比较使用配套的[收集星星原版](授课课件/课堂演示/收集星星_原版.html)和[修改版](授课课件/课堂演示/收集星星_修改版.html)。两个文件是浏览器运行的小程序，PPTX是授课课件。两版均提供“向右移动2秒”按钮，方便比较移动距离。
