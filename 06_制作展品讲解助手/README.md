# 第6课 制作展品讲解助手

[项目首页](../README.md) · [课程资料目录](../00_课程大纲与资料/README.md) · [上一课：完成物品识别提示器](../05_完成物品识别提示器/README.md) · [下一课：建立展品知识库](../07_建立展品知识库/README.md)

## 一、本课定位

语言项目第1课：制作依据短资料回答的校园展览讲解助手，保存语言V1。

面向零基础初中生；每班约30人、8组，每组3～4人；每次90～120分钟。

| 项目 | 本课安排 |
|---|---|
| 核心问题 | 怎样让助手依据资料介绍作品？ |
| 重点讲解 | 资料提供事实，提示词规定任务与表达；回答需要核对依据。 |
| 学生实操 | 修改讲解对象和规则，用五道固定题比较两版提示词的效果。 |

## 三、课前准备

**硬件与物品：**每组一台能访问课程平台的电脑、浏览器和小组账号。本课不连接摄像头或开发板。

**软件与文件：**教师已部署的Dify课程平台及通义模型；学生通过浏览器操作，不安装服务器软件、不填写API Key。

1. 按教师全程演练指引完成平台部署和模型配置，以小组账号实际运行一次模板。
2. 应用按A01～A08、B01～B08命名。共享工作区的Editor账号可编辑其他组内容，明确只操作本组应用。
3. 分发问题表，教师保留参考判断。课堂使用样例资料时，说明它是虚构教学文本。

## 四、课堂安排

按以下顺序组织课堂；各环节时长以本课完整教学设计为准。

1. 先以参观者身份提问，再指出回答对应的资料。
2. 放入短资料，轮流修改讲解对象、任务范围、表达长度和缺资料处理规则。
3. 完成五题测试，分别判断事实依据、任务完成和表达清晰程度。
4. 针对一项主要问题改规则，新建会话用同一问题复测。
5. 保留两版提示词、原始问题与实际回答，保存语言V1。

## 五、成果检查

- [ ] 每人修改过一项规则，并能说明对应结果。
- [ ] 有依据的问题能找到来源；缺资料时应说明缺失，不能编造。
- [ ] 保留五题记录及至少一道题修改前后的完整回答。

## 六、课后衔接

**课后任务：**每人补充两条有来源的资料或提出一个参观问题，小组整理10～20条。自己的事实注明“本组作品记录”。

**下次课准备：**语言V1备份、文本资料、来源及参观问题。

课后基础任务约30～60分钟。没有家庭电脑时，先整理材料与记录，再到学校开放机房操作。
