# 第6课 制作展品讲解助手

本课面向零基础初中生，每班约30人，分为8组，课时为90～120分钟。

## 教学目标

学生能够利用一份简短资料建立有明确用途的讲解助手，修改对象、任务和表达要求，并用相同问题比较变化。资料为回答提供事实依据，提示词说明要完成什么任务、怎样表达。学生通过实际回答检查这两部分是否起作用。

## 成果与评价

提交讲解助手V1、两版提示词和五题测试记录。每名学生指出自己的一项修改及对应结果。教师检查回答是否有依据、是否符合讲解对象，以及学生能否解释自己的修改。
