# 第7课 建立展品知识库

本课面向零基础初中生，每班约30人，分为8组，课时为90～120分钟。

## 教学目标

学生能够整理带来源的短条目，查看知识库分段和检索结果，区分资料缺失、没有检索到和生成错误。重点是“先找相关资料，再据此回答”。知识库不会重新训练大模型。

## 成果与评价

提交资料集、V2和八题记录。基础要求是来源可追溯、能回答已覆盖的事实、知道缺资料时如何处理。资料条数多不单独加分，教师记录每名学生在整理、上传、核对或查找问题时完成的具体操作。
