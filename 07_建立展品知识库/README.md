# 第7课 建立展品知识库

[项目首页](../README.md) · [课程资料目录](../00_课程大纲与资料/README.md) · [上一课：制作展品讲解助手](../06_制作展品讲解助手/README.md) · [下一课：添加知识挑战功能](../08_添加知识挑战功能/README.md)

## 一、本课定位

语言项目第2课：让助手先检索资料，再据此回答，保存语言V2。

面向零基础初中生；每班约30人、8组，每组3～4人；每次90～120分钟。

| 项目 | 本课安排 |
|---|---|
| 核心问题 | 怎样从更多资料中找到回答依据？ |
| 重点讲解 | 资料整理、分段、关键词检索、回答引用；上传知识库不会重新训练大模型。 |
| 学生实操 | 建立本组知识库，绑定讲解应用，核对八道题的检索内容与实际回答。 |

## 三、课前准备

**硬件与物品：**每组一台电脑、浏览器、小组账号、第6课应用备份及文本资料。

**软件与文件：**Dify课程平台；普通文本、通用分段、经济型索引。教师统一模型配置。

1. 检查各组知识库权限和第6课备份，避免覆盖其他组资料。
2. 用公共样例演练：UTF-8文本、空行分隔、500字符、重叠0；预览应为12个完整条目。
3. 自编资料逐条核对编号、主题和来源；分段后编号与事实应在同一段。

## 四、课堂安排

按以下顺序组织课堂；各环节时长以本课完整教学设计为准。

1. 先人工找到一道问题的依据，再观察平台怎样检索。
2. 整理并上传资料，预览分段，等待索引完成。
3. 用展品名和具体关键词测试检索，确认返回内容包含答案。
4. 导入第7课模板，绑定本组知识库，查看模型实际接收的检索内容。
5. 完成八题测试及一个同义问法，对照原文、检索结果、回答定位问题。
6. 保存原文、知识库名称、语言V2配置及测试记录。

## 五、成果检查

- [ ] 每人参与资料整理、上传、核对或问题定位。
- [ ] 回答引用的编号确实存在于检索结果，且内容支持结论。
- [ ] 能区分原文缺资料、检索未找到和生成错误；八题有原始记录。

## 六、课后衔接

**课后任务：**每人补一条资料和对应问题，小组再试一个同义问法。可比较新旧资料，讨论如何处理冲突。

**下次课准备：**更新后的资料原文、语言V2、知识库名称和实际检索记录。

课后基础任务约30～60分钟。没有家庭电脑时，先整理材料与记录，再到学校开放机房操作。
