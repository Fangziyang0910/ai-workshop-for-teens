# 第3课 用灯阵显示识别结果

[项目首页](../README.md) · [课程资料目录](../00_课程大纲与资料/README.md) · [上一课：训练自己的物品分类器](../02_训练自己的物品分类器/README.md) · [下一课：测试并改进识别效果](../04_测试并改进识别效果/README.md)

## 一、本课定位

视觉项目第2课：把分类结果变成可见提示。沿用第2课的类别与模型。

面向零基础初中生；每班约30人、8组，每组3～4人；每次90～120分钟。

| 项目 | 本课安排 |
|---|---|
| 核心问题 | 怎样让开发板显示电脑的识别结果？ |
| 重点讲解 | 条件判断，以及摄像头取图、电脑分类、开发板显示的分工。 |
| 学生实操 | 连接开发板，修改灯阵图案，先检查手动显示，再接入模型预测。 |

## 三、课前准备

**硬件与物品：**每组一台Windows电脑、一只C270摄像头、一块micro:bit V2、一根支持数据传输的Micro-USB线、上一课的物品和模型。

**软件与文件：**Mind+实时模式；先运行灯阵连接检查工程，再打开识别与灯阵联动工程。图像分类在电脑运行。

1. 提前准备实时通信固件，按系统需要处理串口驱动，确认数据线可以通信。
2. 恢复第2课模型。将开发板固定在底座上，避免线材悬吊。
3. 示例对应关系为胶棒→左箭头、橡皮→右箭头、背景→横线。归位区贴上对应标签。

## 四、课堂安排

按以下顺序组织课堂；各环节时长以本课完整教学设计为准。

1. 指出摄像头、电脑、开发板的作用，恢复上一课分类器。
2. 打开连接检查工程，连接串口并显示图案。每人修改并显示一次。
3. 查看手动标签与图案的条件判断，依次核对三类输出。
4. 打开联动工程，加载模型，用预测标签驱动灯阵，同时保留屏幕标签。
5. 交换测试三类输入和暂停操作。先判断错误出在模型、显示规则还是连接，再修改。
6. 保存联动工程、模型、图案对照表和接线照片。

## 五、成果检查

- [ ] 三类标签各有明确图案；空背景和暂停状态显示等待横线。
- [ ] 每人完成一次连接或图案修改，能解释系统中一个部件的作用。
- [ ] 能说明仅给开发板接电池不能继续运行本课程的图像分类。

## 六、课后衔接

**课后任务：**请一位没有参与制作的人按图案操作，记录最不清楚的一步。可在副本中修改暂停提示，或制作固定支架。

**下次课准备：**可恢复的装置、模型、联动工程、图案对照表和一条使用反馈。

课后基础任务约30～60分钟。没有家庭电脑时，先整理材料与记录，再到学校开放机房操作。
