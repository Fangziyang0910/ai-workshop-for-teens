# 第3课 用灯阵显示识别结果

本课面向零基础初中生，每班约30人，分为8组，课时为90～120分钟。

## 教学目标

学生能够连接micro:bit，修改灯阵图案，把模型标签与图案的对应关系为实体提示，并说明电脑识别、开发板显示的分工。重点是理解条件判断，并把上一课的分类结果显示到开发板上。

## 成果与评价

小组提交实体提示装置、三类标签与图案的对应关系和接线说明。每人能连接或修改一次显示，并能独立指出一个系统部件的作用。基础完成标准为三类标签各有明确输出，空背景进入等待提示。
