# AI创想工坊学生任务卡与课后实践

每组使用本组设备和文件夹，课堂轮换操作。先完成基础任务，再选择挑战。遇到问题先记录“做了什么、看到了什么”，把记录交给老师；不要反复删除文件或更换软件。

每次离开前完成三件事：保存自己的文件；请另一位成员打开一次；写清下次从哪里继续。课后基础任务约30～60分钟，没有家庭电脑时可先整理材料，再到学校开放机房操作。

## 第一课 AI侦探

**本课任务：了解AI的能力，解释一个工作过程，并实际检查结果。**

1. 观看近期官方演示，说明它接收什么信息、得到什么结果。
2. 根据卡片的具体做法分类。每人至少解释一张，指出判断依据。
3. 轮流测试手写数字分类器。先预测，改变数字写法或一段笔画，再记录实际结果。
4. 观看教师让DeepSeek制作贪吃蛇，再提出速度减半的修改要求，检查实际效果和原有功能。
5. 对照社团资料核对时间与费用，再写下自己的工具想法。

使用[第一课学生活动材料](../01_AI侦探/学生活动材料/第一课_AI侦探_学生活动材料.pdf)：案例卡、分类底板、分类器测试记录和课末记录。

课末独立回答四题：今天想继续尝试哪项AI能力，为什么；一个例子的输入、处理和输出；怎样核实“50元材料费”；想给谁做什么工具，准备怎样检查。

**课后基础任务：**观察一个熟悉的AI功能，记录它的输入、结果及一条需要核实的信息。准备两类清洁、轻便、便于拍摄的小物品，例如胶棒和橡皮。学生不需要注册新平台。

**可选挑战：**比较固定时间提醒和社团问答分别需要什么工具，说明选择理由。没有家庭电脑时先做观察和物品准备。

## 第二课 训练自己的物品分类器

**今天的问题：怎样让电脑学会我们选定的类别？**

使用电脑、摄像头和Mind+。本课不连接开发板。完整操作见[视觉手册](视觉项目操作手册.md)。

1. 写下两类物品和背景。统一示例为胶棒、橡皮、空背景。
2. 按老师演示拍摄，每类约20张。换位置和角度，三类轮换使用相同的背景。
3. 将图片放入对应文件夹，检查没有混入别类图片。
4. 在Mind+中初始化一次，导入三类图片，完成建模，再开启识别。
5. 用另一件同类物品或新位置测试，记录一次正确结果，以及一次与预想不同的结果；若暂时没有错误，记录表现稳定的条件。
6. 保存工程、模型和原图；换一位同学重新打开。

**完成后检查：**□每人采样或导入 □三类都能得到预测 □知道分类器只能从已有类别中选择 □另一人能恢复。

**课后基础任务：**打开工程并加载模型，在一种新背景下试5次。每次写真实物品与预测结果，先不急着全部修复。

**可选挑战：**换成自己真正需要分类的物品。保留课堂版本，使用新文件名。

**下次课带齐：**工程、模型、三类图片、5次记录。出现问题时提供错误画面和操作步骤，不只写“坏了”。

## 第三课 用灯阵显示识别结果

**今天的问题：怎样让开发板显示识别结果？**

使用上一课模型、摄像头、micro:bit和数据线。

1. 连接开发板，先只显示一个图案。
2. 每个人修改并显示一次图案。
3. 手动把标签改为`glue`、`eraser`、`background`，检查左箭头、右箭头和横线。
4. 把手工标签换成模型预测，屏幕上保留标签显示。
5. 轮流放入两类物品和空背景，分别看屏幕标签与开发板图案。
6. 保存程序、模型、图案对照表和接线照片。

**完成后检查：**□三类有明确图案 □解释摄像头、电脑和开发板各做什么 □知道只改显示图案时不用重新训练模型。

**课后基础任务：**请一个没有参与制作的人根据图案操作，记下他最不清楚的一步。

**可选挑战：**在副本中修改暂停提示，或做一个固定摄像头的支架。先保存原程序。

**下次课带齐：**当前装置和一条使用反馈。开发板不能显示时先试独立图案，先确认显示正常，再检查分类器。

## 第四课 测试并改进识别效果

**今天的问题：错误从哪里来，哪一个改变有帮助？**

1. 邀请别人操作，写一个具体问题，例如某位置的胶棒总被认成背景。
2. 写自己的猜想，决定主要改变哪个条件。
3. 按[十八次测试表](配套材料/视觉项目测试表与作品说明.md)完成第一轮：原条件、换背景、变位置，各三类两次。
4. 复制为V2，选择补样本或改结构中的一项主要改动。
5. 在相同条件下复测，保留没有改善或变差的结果。
6. 写出问题、猜想、改动和结果。

**完成后检查：**□保存V1与V2 □记录实际错误 □每次只改一项主要内容 □说明结果在哪些测试条件下成立。

**课后基础任务：**每个人寻找一个没有测过的条件，小组选一项继续检查。

**可选挑战：**比较增加相同画面与增加不同角度是否有区别，尽量保持数量相近。

**下次课带齐：**两个版本、测试表和改进卡。没有提高也可以完成任务，关键是记录真实、解释清楚。

## 第五课 完成物品识别提示器

**今天的问题：别人能不能按照说明使用它？**

1. 一句话说明作品帮助谁做什么。
2. 从关闭状态重新启动，写下实际需要的步骤。
3. 制作底座，固定摄像头和开发板，用标识划出物品摆放区域。
4. 写启动、摆放、反馈、停止四步说明，标明需要电脑。
5. 邻组独立完成六项用户任务，设计者先观察。
6. 修复一个最影响使用的问题，完成一分钟演示和归档。

**完成后检查：**□别人能看懂提示 □结构不挡镜头 □能说明一个适用条件 □每人解释一次自己的工作。

**课后基础任务：**请家人或同学试用，记录一句反馈。把作品写成4条事实：用途、组成、规则、使用范围。

**可选挑战：**画一张更清楚的系统图，或优化一个标识。

**下次课带齐：**视觉档案和短资料。只填写有记录的测试结果、实际费用和奖项；没有依据的项目留空。

## 第六课 制作展品讲解助手

**今天的问题：怎样让助手依据资料介绍作品？**

使用课程网址和本组应用，老师已经配置模型。

1. 打开本组讲解助手，先提一个问题，找到回答来自哪条资料。
2. 阅读[短资料](配套材料/第6课_展品短资料.txt)，也可以使用上一课整理的本组4条事实。
3. 四人轮流修改服务对象、任务范围、表达方式、不知道怎么办。
4. 按五道固定题测试，分别看事实、任务与表达。
5. 选一个主要问题改规则，新建会话用同一问题再试。
6. 保存两版提示词，并分别保留完整问题和实际回答。

**完成后检查：**□回答有内容 □能找到依据 □缺资料会说明 □每人改过一项规则。

**课后基础任务：**每人补两条有来源的资料或提出一个参观问题，小组整理10～20条。自己作品的事实写来源“本组作品记录”。

**可选挑战：**用同一资料向不同年龄的人讲解，比较哪种表达更清楚。

**下次课带齐：**文本资料与问题。家庭访问使用课程账号，模型服务由老师统一管理。

## 第七课 建立展品知识库

**今天的问题：怎样从更多资料中找到回答依据？**

1. 整理每条事实的主题、编号和来源。
2. 上传文本到本组知识库，预览分段，确认编号和事实没有分开。
3. 在检索区域问一个具体问题，先看返回资料有没有答案。
4. 将本组知识库接入讲解助手，检查模型能使用检索结果。
5. 测试有答案、没有答案和换一种说法的问题。
6. 保存原文与应用配置，解释一个问题发生在哪个环节。

**完成后检查：**□资料有来源 □看过检索结果 □能区分没查到资料和回答写错 □原文单独保存。

**课后基础任务：**每人补一条资料和对应问题，小组试一个同义问法。

**可选挑战：**给一条旧资料标上日期，与新资料比较，说明应怎样更新。

**下次课带齐：**更新原文、检索问题与实际回答。上传资料不等于重新训练大模型。

## 第八课 添加知识挑战功能

**今天的问题：怎样让参观者既能了解内容，也能参与挑战？**

1. 先在纸上画两条路径：讲解、挑战。
2. 在入口选择任务和展品，输入自己的要求。
3. 看条件节点怎样选择路径，修改一项规则。
4. 修改讲解要求或挑战题格式；题目答案必须有资料依据。
5. 完成八次路径测试，分别检查进入的分支和输出内容。
6. 请邻组体验一道题，保存V3和流程图。

**完成后检查：**□两种任务有区别 □两条路径都能解释 □题目有唯一正确答案和资料依据 □任务冲突有明确处理。

**课后基础任务：**请一人体验讲解和挑战，记录一处停顿或不清楚的地方。

**可选挑战：**在副本中用模型自动判断任务，记录何时选错。保留明确选择版本。

**下次课带齐：**实际输入、输出和体验反馈。基础版在题目后给出答案，请先作答，再自行核对。

## 第九课 试用并改进讲解助手

**今天的问题：别人怎样使用我们的作品，最重要的问题是什么？**

1. 交换工位，请对方先读简短说明，再独立使用。
2. 观察选择展品、讲解、事实问答、挑战、缺资料问题和结束六项任务。
3. 对照十五题测试补齐遗漏，保留原始回答。
4. 选择最影响使用的一项问题，修改资料、规则或入口说明。
5. 复测答错的题目，再抽查原来回答正确的题目。
6. 完成一页说明和一分钟演示，确认两个项目文件齐全。

**完成后检查：**□观察者没有代操作 □有修改前后证据 □资料和应用配置属于同一版本 □每人有具体贡献。

**课后基础任务：**练习三分钟展示，录一段连续演示，每人承担一段。

**可选挑战：**制作一页海报，突出用途、过程、改进和证据。

**下次课带齐：**稳定版文件、设备、视频与分工。展示前不临时整体更换模型或软件。

## 第十课 校园AI创客展

**今天的问题：怎样让别人理解作品，也理解我们的工作？**

1. 按清单布展，完成启动检查。
2. 每组用3分钟展示、2分钟问答。重点展示一项作品，另一项用短视频或简要说明呈现。
3. 每人参观至少两组，实际体验至少一项作品。
4. 给出一条具体反馈，说明什么地方好用或不清楚。
5. 完成个人总结，归档文件并核对设备交接。

**个人总结：**我亲手完成了____；我原来认为____，现在认为____；我能解释的一次失败____；我最想继续研究____。

**后续探索：**选择一个实际问题，继续改进，不必同时增加很多功能。参加活动时准确说明自己做的部分、老师帮助的部分和工具提供的部分。
