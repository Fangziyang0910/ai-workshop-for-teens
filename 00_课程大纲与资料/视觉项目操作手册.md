# 桌面物品识别提示器操作手册

本手册供第1～5课备课、课堂演示及课后操作使用。使用Windows版Mind+ V1.8.1 RC3.0、USB摄像头和micro:bit V2。学生无需安装Python，也无需申请图像识别API。

## 一、软件与工位准备

1. 从[Mind+官方下载](https://mindplus.cc/download.html)进入V1.x下载区域，选择Windows V1.8.1 RC3.0。页面同时提供V2，课程不混用两个系列。
2. 安装到教师电脑和16台学生电脑，使用同一安装包。保存安装包到校内共享位置；学校账号应有摄像头和课程目录写入权限。
3. 打开软件，切换“实时模式”。在扩展的功能模块中加入“机器学习ML5”；在主控板中加入micro:bit。第2课只操作ML5部分。
4. 将C270连接到USB口，先用Windows相机确认画面。退出相机程序再打开Mind+，避免同时占用。支架夹持摄像头原装底座，画面应清楚覆盖桌面区域。
5. 新建固定文件夹，例如`A01_视觉项目`，下设`原图/glue`、`原图/eraser`、`原图/background`、`模型`、`工程`、`测试`、`说明与视频`。将目录放在机房还原软件不会自动清空的位置，并另存一份备份。
6. 第3课前连接开发板，在Mind+选择micro:bit串口，按软件提示安装实时通信固件。Windows 10/11通常使用系统自带的micro:bit串口驱动。先检查设备管理器；只有连接异常时才按官方FAQ处理。不要为正常连接的设备重复安装旧版Mbed驱动。

[ML5官方步骤](https://mindplus.dfrobot.com.cn/ml5-knn)说明了离线分类、图像导入和模型保存；[micro:bit实时教程](https://mindplus.dfrobot.com.cn/DFR0497)说明开发板连接；[FAQ](https://mindplus.dfrobot.com.cn/FAQ)用于摄像头、驱动与模式问题。

## 二、课程程序的组成

教师可从[Mind+起始工程](配套材料/MindPlus工程/README.md)打开对应文件，再按下列结构检查和修改。积木使用功能名称描述；缩进表示嵌套，不是要输入的代码。ML5的模型、结果和摄像头积木均从同一扩展中选择。

### （一）初始化脚本

```text
当绿旗被点击
  将“运行”设为0
  将“当前标签”设为空
  使用弹窗显示摄像头画面
  开启摄像头
  等待5秒
  初始化KNN分类器
  提示：采集新样本，或加载已有模型
```

每次打开工程后只执行一次初始化。已有模型尚未保存时不反复点绿旗。初始化后选择“从原图建模”或“加载旧模型”其中一条路径。

### （二）从原图建立分类器

基础课程采用可保存原图的文件夹导入方式。教师可在准备时使用Windows相机拍摄备用样本；学生现场采样也使用同一方法。

1. 停止Mind+识别并关闭摄像头，打开Windows相机。每次只放一种类别，每类拍20张左右；改变位置和角度，避免连拍相同画面。
2. 从相机的照片保存位置取出刚拍的图片，分别复制到三个类别文件夹。删除无关照片，核对文件数量。每类文件夹不得混入另一类。
3. 完成采图后关闭Windows相机，回到Mind+开启摄像头。初始化仅在尚未初始化时执行；需要完全重新建模时先保存旧版，再清除分类器数据。
4. 按以下顺序使用“从本地文件夹图片加入类别”的积木，点击积木中的文件选择控件选择对应目录。路径保存在本机，换电脑时重新指定。

```text
停止KNN摄像头分类识别
将glue文件夹图片加入类别glue
将eraser文件夹图片加入类别eraser
将background文件夹图片加入类别background
开始分类训练
训练完成后：开启KNN摄像头分类识别
```

每类20张是课堂任务规模，不是算法必须数量。本版本一次文件夹导入最多读取50张，文件扩展名统一用小写`.jpg`、`.jpeg`或`.png`。电脑较慢时先用每类10张，完整运行后再增加。采样和训练时不同时运行识别；添加或删除样本后重新训练。

### （三）快速摄像头采样方式

用于教师展示或完成基础任务的小组：设置三个按键，分别把当前画面加入三类。按一次加入一次，逐次改变姿态。另设训练按键，在采样完成后启动训练。

```text
按1：停止识别；将摄像头画面加入类别glue
按2：停止识别；将摄像头画面加入类别eraser
按3：停止识别；将摄像头画面加入类别background
按T：停止识别；开始分类训练；完成后开启识别
```

直接加入分类器的画面不会自动保存为独立图片。需要保留原图时，使用上一节的文件夹导入方法。工程和原图应分别保存。

### （四）屏幕预测与暂停

```text
按S
  开启KNN摄像头分类识别
  将“运行”设为1
按P
  将“运行”设为0
  停止KNN摄像头分类识别
  将“当前标签”设为background
  第3课起：显示横线等待图案

当绿旗被点击
  重复执行
    如果“运行”=1
      将“当前标签”设为KNN识别分类结果
      在舞台显示“当前标签”
    等待0.2秒
```

在模型已建成或已经加载后才按S。暂停后可以调整摆放、采样或讨论。结束操作前仍需保存文件。不要用“停止所有脚本”作为唯一暂停方式，以免返回时误点绿旗清空状态。

### （五）保存与恢复

保存顺序：停止识别；使用ML5的分类模型保存功能选择`模型`目录；通过项目菜单保存Mind+工程；检查`原图`目录和测试表。工程使用软件默认`.mp`格式，本版本导出分类模型为`.json`，保留导出器给出的文件名。

恢复顺序：打开工程；连接摄像头；执行一次初始化；从保存位置加载分类模型；启动识别。加载后不再清空分类器，不用旧训练按钮覆盖已恢复的模型。换电脑时重新选择模型路径和摄像头。

工程、模型和原图应分别保存。工程保留程序，模型用于再次识别，原图用于补充训练和说明数据来源。

## 三、开发板连接与灯阵控制

### （一）单独检查灯阵

1. 用Micro-USB数据线连接开发板与电脑；摄像头使用另一个USB口。
2. 在实时模式下加载micro:bit，选择对应串口，完成连接。开发板的通信固件用于接收电脑指令，不会把图像分类模型复制进开发板。
3. 拖入灯阵显示积木，手动绘制左箭头并执行，再改为右箭头。每名学生操作一次。
4. 出现“有电但无响应”时先换数据线，再查设备管理器端口和通信固件。无需先改模型。

### （二）手动标签测试

创建变量`当前标签`。在不启动模型时，手工设定三种值，运行下列结构。使用嵌套“如果—否则”，保证每次只选择一种输出。

```text
如果当前标签=glue
  显示左箭头
否则
  如果当前标签=eraser
    显示右箭头
  否则
    显示横线等待图案
```

两处归位区域按箭头方向贴中文标签。全组统一使用这里列出的三个小写英文标签，不添加空格，也不用仅大小写不同的词表示不同类别。解释与操作卡使用中文。

### （三）接入模型

将前述屏幕预测循环中的当前标签变量接入显示规则，每次间隔约0.2秒。只有“运行”=1时读取模型并更新目标图案；“运行”=0时始终显示等待横线。先同时显示屏幕标签和开发板图案，确认一致后再调整外观。停止时显示横线，不继续保留上一次目标提示。

检查六项：胶棒标签、胶棒图案、橡皮标签、橡皮图案、背景标签、背景图案。第一次连接先使用原来已知能正确分类的输入，避免模型和硬件同时引入新问题。

## 四、第4课改进与第5课制作

### （一）三种条件下的十八次测试

设置三种条件：原场景、只换背景、只改位置。每种条件下，胶棒、橡皮和背景各测2次，共18次。按[配套测试表](配套材料/视觉项目测试表与作品说明.md)填写。第一轮使用V1，第二轮使用V2，条件保持相同，补充训练图片另行拍摄，不把测试图片直接加入训练集。

遮挡物品、多件混放和未见过的物品都超出了基础测试范围。三类分类器仍会将这些输入分到已有类别，不能据此判断它具有未知物品检测能力。作品说明应写明：一次只放一件物品，并放入指定区域。

### （二）拓展任务 减少图案跳动

当输出在相邻帧间跳变时，可在副本中加入简单确认：每0.2秒读取一次结果；与上一结果相同时计数加1，否则把候选改成新结果并把计数设为1；连续3次相同后更新图案。暂停立即恢复等待图案。

连续确认可以减少图案跳动，但提示会稍有延迟。它不能纠正持续出现的分类错误。学生应比较使用这条规则前后的显示效果，并区分“图案更稳定”和“分类更准确”。

### （三）制作要求

制作纸板底座时，先固定摄像头，再标出物品区域，放好开发板，整理连接线。开发板灯阵应朝向使用者。摄像头画面变清晰后，用胶带标记当前距离与位置；物品距离按画面清晰程度调整。结构遮挡或移动后重新检查分类。

写四步使用说明：启动、摆放、理解反馈、暂停或结束。另写输入范围和需要电脑保持连接。邻组先独立试用，设计者观察，再作修改。

## 五、家庭继续操作

1. 使用学校提供的同版本安装包，不改用网页版本。
2. 复制本组完整项目目录，先打开工程再加载模型。
3. 接入本组摄像头，恢复画面与光照；有开发板时连接开发板，无开发板时可完成屏幕分类测试。
4. 先测试原条件，再完成任务卡上的一个变化。
5. 保存为新版本，原版本保留；交接时把文件与设备一起交给下一位成员。

没有家庭电脑时，先准备测试物品、记录拍摄条件或画出提示图案，在校内开放时段操作。设备不能长期由同一成员保管。

## 六、故障处理表

| 现象 | 首先检查 | 处理步骤 |
|---|---|---|
| 摄像头黑屏 | 被相机或会议软件占用、相机权限、USB | 退出占用程序；Windows相机确认；在Mind+重新选择 |
| 训练不结束或卡顿 | 样本量、后台占用、反复触发 | 等待当前任务；减少到每类10张；关闭无关程序 |
| 所有输入都归一类 | 标签与文件夹、样本是否实际导入 | 检查三目录；保存旧模型后重新建模 |
| 只有某背景正确 | 类别与背景绑定 | 各类交叉使用背景，另拍变化样本 |
| 原图路径找不到 | 换电脑后路径改变 | 重新选文件夹，不修改标签 |
| 开发板亮电源却不显示 | 数据线、端口、模式、固件 | 先用独立显示程序；更换线；恢复实时连接 |
| 标签正确但图案错误 | 判断规则、大小写、旧循环 | 手动输入三标签，确认唯一输出循环 |
| 模型恢复后结果丢失 | 重新初始化或清空 | 从保存模型再次加载；调整启动顺序 |
| 输出跳动 | 真实画面变化或分类不稳定 | 固定输入；改善数据；必要时连续确认三次结果后再显示 |
