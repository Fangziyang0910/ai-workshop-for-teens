# AI创想工坊课程介绍与教学大纲

## 一、课程简介

“AI创想工坊”面向初中零基础学生，通过制作两项作品学习人工智能。学生先认识AI的基本能力，再完成“桌面物品识别提示器”和“校园展览讲解助手”，通过采集数据、整理资料、修改程序、测试改进和成果展示，理解人工智能怎样参与解决具体问题。

课程共10次，每月一次，每次90～120分钟。学生在课堂上完成基本功能，在两次课之间按任务卡继续练习。课程使用图形化编程和可视化应用平台，学生通过拖动积木、修改文字和连接节点完成操作，无需编程基础。

每次课都安排动手任务。视觉项目中，学生采集物品图片，让开发板显示识别结果。语言项目中，学生整理展品资料，让助手依据资料讲解和出题。教师通过提问和测试，检查学生能否说明作品怎样工作、在哪些条件下可以使用。

## 二、开设目的与学习目标

人工智能已经进入学生熟悉的学习、娱乐和生活场景。学校课程需要让学生在实际操作中建立基本判断：AI接收什么信息，结果依据什么产生，什么地方需要人来定义、检查和改进。

课程围绕以下四项目标安排教学。

1. **理解AI的工作过程。** 学生采集样本、指定标签、查看预测，再把结果显示到开发板上。通过这一过程，理解数据、模型和输出之间的关系。
2. **完成自己的设计。** 教师提供基础程序。学生选择物品、设计图案、编写讲解要求，并整理本组资料。每名学生都要完成一项修改，并说明它的作用。
3. **学会测试和改进。** 学生保留错误结果，比较修改前后的表现，核对回答来源，说明改了什么、为什么改、结果如何。
4. **积累科创实践经验。** 学生保存源文件、资料、测试记录和个人分工，用于校园科技节或社团展示。有兴趣的小组可继续研究实际需求，完善作品，再按赛事要求准备参赛材料。

完成课程后，学生应能解释一个简单AI系统的输入与输出，参与制作视觉和语言应用，独立完成一次修改与测试，并向同学说明自己的工作。课程评价兼顾个人参与、理解、作品运行和表达，不以硬件价格、代码数量或获奖情况作为主要标准。

| 规模 | 两个班同时授课，每班约30人，共约60人 |
| 分组 | 每班8组，每组3～4人，共16组 |
| 周期 | 10个教学月份，共10次课 |
| 课时 | 每次90～120分钟，总计15～20小时 |

| 结课成果 | 每组一项视觉作品、一项互动讲解应用及相应档案 |

## 四、项目一 桌面物品识别提示器

### （一）项目情境

使用者把一件文具放到摄像头前，电脑判断类别，开发板灯阵显示对应的归位方向。学生也可以把同一方法用于社团物资整理或卡片互动。统一示例为胶棒、橡皮与空背景，学生完成基础任务后可以换成自己的两类物品。

### （二）学生学习与制作内容

第2课选择类别并采集图片，建立能在屏幕上运行的分类器；第3课连接micro:bit，把识别结果变成实体图案；第4课更换背景、位置或操作者，发现问题并改进；第5课完成结构、说明和交换试用。

学生学习样本、标签、预测和条件判断，并说明各个部件的作用。电脑负责图像分类，micro:bit开发板负责显示；普通办公电脑即可承担课程中的分类任务，无需独立显卡。

### （三）作品要求

作品能区分两类物品与采集过的背景，输出图案有清楚含义，另一名同学可以按说明使用。小组保留一次改进前后的测试，说明装置适合什么条件。摄像头与开发板始终配置给每组，保证两班同时实践。

## 五、项目二 校园展览讲解助手

### （一）项目情境

校园展览中，参观者希望了解作品，也希望参与简单互动。学生为自己的视觉作品或其他校园展品制作一个通过文字交互的讲解助手，能够根据资料回答问题，并提供一道有依据的知识挑战。

### （二）学生学习与制作内容

第6课使用短资料完成有实际内容的讲解助手，修改讲解对象、范围与表达；第7课整理更多资料并加入检索；第8课设置“讲解”和“挑战”两条路径；第9课请同伴试用，完成最后一次有依据的改进。

教师管理课程平台与国内模型接口，学生通过浏览器编辑和测试。基础版由参观者明确选择任务；自动判断意图作为拓展。课程不要求学生维护服务器、购买模型服务或注册境外账号。

### （三）作品要求

应用具有明确主题，回答能找到资料依据，资料缺失时说明信息不足；讲解和挑战两种功能各有明确用途；挑战题的答案和解释能够核对。学生保留原始资料、提示词、应用配置和测试记录。

两个项目可在结课展览中相互支持：视觉装置作为展品，语言助手向参观者介绍装置的用途和工作过程。软硬件结合由视觉项目完成，语言项目不强制增加语音和机械控制。

## 六、十次课教学大纲

| 课次与主题 | 核心问题 | 讲授内容 | 实践任务与成果 |
|---|---|---|---|
| 第1课 AI侦探 | AI能做什么，怎样检查结果 | 近期能力展示、模型学习与使用、模型与程序分工、资料核对 | 判断案例、测试分类器、比较程序版本，提出作品想法 |
| 第2课 训练自己的物品分类器 | 怎样让电脑识别自己选择的类别 | 样本、标签、预测与任务范围 | 采样、建模、保存，完成视觉原型 |
| 第3课 用灯阵显示识别结果 | 怎样用开发板显示识别结果 | 摄像头、电脑、规则与开发板的分工 | 连接开发板、修改图案、联动标签，完成提示装置 |
| 第4课 测试并改进识别效果 | 为什么实际使用时会出错 | 数据变化、条件控制与版本比较 | 按表测试、补样本或改结构，记录前后结果 |
| 第5课 完成物品识别提示器 | 怎样让别人独立使用作品 | 用途、结构、标识和说明 | 结构制作、交换试用、小展示，完成视觉作品 |
| 第6课 制作展品讲解助手 | 怎样用资料完成清楚的讲解 | 任务、上下文、事实与表达 | 加短资料、改提示词、用同一问题比较，完成讲解助手V1 |
| 第7课 建立展品知识库 | 怎样查资料并给出有依据的回答 | 来源、分段、检索与核对 | 整理上传资料、检查回答，完成讲解助手V2 |
| 第8课 添加知识挑战功能 | 怎样满足了解内容和参与挑战两种需求 | 明确选择、条件分支与任务流程 | 编辑讲解与挑战、核对路径和题目，完成互动版 |
| 第9课 试用并改进讲解助手 | 别人遇到的问题应该怎样解决 | 用户观察、问题优先级与复测 | 邀请同伴试用、修改、复测，完成语言作品 |
| 第10课 校园AI创客展 | 怎样解释作品和自己的贡献 | 演示、证据与学习反思 | 展示问答、轮换体验、个人总结，整理作品档案 |

## 七、教学组织与学生支持

课堂每次解决一个主要问题，先展示完整效果，再讲必要概念，再让学生操作和修改。教师分步示范，每一步说明预期现象。90分钟完成基础要求，120分钟增加自主尝试和交流。

每组操作位每10～15分钟轮换，记录、材料与发言职责随活动调整。每名学生至少完成一次实际操作，并能说明对应作用。完成基础任务的学生可选择挑战任务。进度较慢的学生先完成本课必要步骤，由助教协助检查。每名学生都应有实际操作和解释的机会。

每课提供课后操作与交接卡，说明恢复方法、一个基础任务、一个可选挑战和提交内容。没有家庭电脑的学生使用学校开放机房；观察、资料整理与纸面设计可先在家完成。设备按组轮用，教师定期收取备份并集中解答问题。

## 八、实施条件与投入

| 条件 | 安排 |
|---|---|
| 师资 | 两班各1名主讲；硬件课各1名助教；指定平台技术负责人 |
| 场地 | 每班8个小组工位、投屏与可用电源；16台学生电脑可同时连接摄像头与开发板 |
| 本地软件 | 统一Mind+ V1桌面版；视觉项目本地运行 |
| 在线服务 | 国内部署Dify课程服务，连接国内语言模型；学生通过课程网址访问 |
| 家庭实践 | 学校提供安装材料、小组账号、保存方法和问题反馈渠道 |
| 经费 | 器材、备件、打印与公共配件、10个月服务器、模型费用及预备金合计按13,500元安排 |

课程使用学校现有电脑，上述预算不含教师与助教课酬、技术部署维护人工和新增场地费用。小组设备平均约490元，另计公共备件和服务。具体数量、规格与计算见[实施方案第十六部分](课程实施方案与分课教学设计.md#十六设备配置与经费安排)。

服务器负责应用和检索，不训练大模型。语言模型按实际调用计费，课程统一设置短回答、调用节奏与费用提醒。学生必修操作不依赖境外网站，外部资料由教师提前整理到课程材料中。

## 九、评价与后续发展

评价包括问题与用途20%、个人参与与理解25%、测试改进25%、运行恢复20%、展示表达10%。教师结合巡视、个人解释、作品和记录作判断，不用小组成果替代个人学习。

每组结课选择一项重点展示，另一项用短视频或简要说明呈现。每班8组，每组3分钟演示、2分钟问答，两班分场同时进行，另安排轮换体验与个人反思。

对愿意继续的学生，学校可组织真实场景调查、长期测试和作品完善，再根据具体赛事当届规则确定参赛队伍与材料。全体学生均可在校园科技节、社团活动或校内展览中展示作品。
