# 课程资料目录

[项目首页](../README.md) · [十课安排](../README.md#二十课安排与材料入口)

## 二、教师备课顺序

1. 阅读课程介绍，确认两项作品及本校的人员、设备和课后实践条件。
2. 按全程演练指引取得资源、安装软件，完成视觉与语言项目各一次完整操作。
3. 从[十课安排](../README.md#二十课安排与材料入口)进入本课README，核对上次课文件、本课设备和材料。
4. 阅读本课完整教学设计，选择90分钟或120分钟流程，演练关键步骤。
5. 发放本课任务卡、工程、资料与记录表；测试题参考判断由教师留存。
6. 课末检查成果，由另一位成员恢复文件，记录课后任务与下一课起点。

第1课另有[教师教案、课件和活动PDF](../01_AI侦探/README.md)。第2～10课的详细教案集中在实施方案中，操作步骤和可发放材料由各课README直接链接；目前没有另列独立PPTX或活动PDF。

## 三、两个项目怎样衔接

| 阶段 | 使用资料 | 需要保留的成果 |
|---|---|---|
| 第1课：认识与体验 | 第一课教案、课件、活动材料、已训练分类器 | 活动记录与作品想法 |
| 第2～5课：桌面物品识别提示器 | 视觉手册、Mind+工程、视觉测试表 | 原图、模型、工程、测试、使用说明，以及四条作品事实 |
| 第6～9课：校园展览讲解助手 | 语言手册、Dify模板、展品资料、语言测试题 | 提示词、资料原文、应用DSL、知识库关联说明与测试记录 |
| 第10课：展示与总结 | 两项作品档案、展示要求与个人总结 | 真实演示、同伴反馈、个人贡献和后续改进问题 |

公共展品资料是虚构教学样例。介绍本组真实作品时，替换为有依据的作品记录，并同步修改测试参考。

## 四、查阅与维护约定

- 每课README说明本课怎么准备和组织；详细时长、提问与评价以分课教学设计为准。
- 软件操作查对应项目手册；固定版本、下载文件和安装命令查本地资源目录。
- 配套材料保留一份共用原件，学生复制到本组目录后修改；视觉与语言项目分别记录版本。
- 大型下载文件保存在本地，不随Git克隆取得。复制到学校前按资源清单校验，具体方法见本地资源目录。

器材及在线服务预算为13,500元，使用学校现有18台电脑；教师课酬和技术维护人工另计。设备数量与经费明细统一见[实施方案第十六部分](课程实施方案与分课教学设计.md#十六设备配置与经费安排)。
