# AI创想工坊课程资料

本目录供学校领导、课程负责人和授课教师使用。课程面向零基础初中生，共10次课，每月一次，每次90～120分钟。两个班同时授课，共约60人，分为16组，每组一套设备。

| [本地资源与安装指引](本地资源/README.md) | 教师、技术负责人 | 本地安装包、官方资料、依赖、下载及校验工具 |

学校介绍课程时使用《课程介绍与教学大纲》。教师首次备课时，先按《教师备课与全程演练》跑通两个项目，再阅读分课教学设计，最后发放本课任务卡和配套材料。

## 项目与经费

第2～5课制作桌面物品识别提示器：先训练分类器，再连接开发板，测试识别效果，最后完成结构和使用说明。第6～9课制作校园展览讲解助手：先根据短资料回答问题，再添加知识库和知识挑战，最后通过同伴试用改进。

器材与在线服务预算共13,500元，包含16套小组设备、公共备件、打印材料、公共配件、10个月服务器、模型调用和预备金。课程使用学校现有18台电脑；教师课酬和技术维护人工另计。明细见[实施方案第十六部分](课程实施方案与分课教学设计.md#十六设备配置与经费安排)。

第一课的详细活动教案、课件和打印材料见[第一课目录](../01_AI侦探/README.md)。
