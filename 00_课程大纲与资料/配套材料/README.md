# 课堂配套材料

教师按课次发放下表材料，学生复制后填写自己的组号和内容。公共展品是明确标注的虚构教学样例；真实作品介绍应以小组实际设计与记录替换。

| 文件 | 课次 | 使用方法 |
|---|---|---|
| [Mind+起始工程](MindPlus工程/README.md) | 第1～5课 | 三类分类、灯阵检查、识别联动；选择本机路径后使用 |
| [短资料](第6课_展品短资料.txt) | 第6课 | 复制到提示词的展品资料区域；四条事实支持首轮讲解 |
| [展品知识库](第7课_展品知识库.txt) | 第7～9课 | UTF-8文本上传，预览分段，保留E01～E12编号 |
| [讲解助手提示词与节点配置](讲解助手提示词与节点配置.md) | 第6～8课 | 复制规则并逐步修改；检索阶段绑定真实上下文 |
| [语言项目测试题与评价参考](语言项目测试题与评价参考.md) | 第6～9课 | 发学生问题表，教师使用参考判断；记录实际输出 |
| [视觉项目测试表与作品说明](视觉项目测试表与作品说明.md) | 第2～5、10课 | 采样、十八次测试、改进、用户试用与展示 |
| [短资料讲解模板](Dify模板/第6课_短资料讲解.yml) | 第6课 | 导入Chatflow，教师配置通义模型后复制16组 |
| [知识库讲解模板](Dify模板/第7课_知识库讲解.yml) | 第7课 | 上传资料并选择本组知识库，在上一课应用中增加检索节点 |
| [讲解与挑战模板](Dify模板/第8课_讲解与挑战.yml) | 第8课 | 选择任务与展品，绑定知识库，分别检查两条路径 |

三个YAML文件按Dify 1.17.1的DSL结构编排。教师先安装课程指定模型插件并配置模型，第7、8课再绑定知识库；文件不包含账号凭证、API Key或知识库正文。导入和绑定方法见[语言项目操作手册](../语言项目操作手册.md)。

视觉起始工程提供三个`.mp`文件及对应JSON源文件；[视觉项目操作手册](../视觉项目操作手册.md)解释积木结构和操作顺序。学生在课堂上采集训练图片。展品文本供语言项目使用，与视觉项目的训练图片分别保存。

教师可直接投屏操作手册和本课任务卡。课件制作时按实施方案的课堂顺序抽取概念、示范和任务；学生材料不需要包含平台部署步骤。
