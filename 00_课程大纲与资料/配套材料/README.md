## 二、Mind+工程使用方法

[Mind+工程目录](MindPlus工程/README.md)提供三份`.mp`及对应的可读JSON源文件。教师和学生在Mind+中打开`.mp`；JSON用于查看与比较工程内容，不作为模型文件加载。

1. 将工程复制到本组目录，按说明选择本机摄像头、串口和文件路径。
2. 第2课采集本组原图并训练，分别保存工程MP、模型JSON和原图。
3. 第3课先运行灯阵检查，再加载本组模型进行联动；第4、5课继续使用本组版本。
4. 具体按键和恢复步骤见工程目录；积木结构与故障处理见[视觉项目操作手册](../视觉项目操作手册.md)。

起始工程不含实拍训练图片或已训练模型。第1课使用已内置模型的手写数字分类器，直接用浏览器打开；第2课起再按工程说明采样、建立文具模型。工程JSON与模型JSON用途不同，分别保存。

## 三、Dify模板使用方法

三个YAML文件用于课程固定版本Dify的Chatflow。平台版本与插件安装包见[本地资源目录](../本地资源/README.md)。

1. 教师先安装课程插件并配置模型，导入第6课模板，确认能运行后准备各组副本。
2. 第7课先保留语言V1，再导入第7课模板、上传资料并绑定本组知识库。导入会建立应用，不会自动修改上一课应用。
3. 第8课保留语言V2，导入两分支模板，重新选择本组知识库，核对任务与展品选项。
4. 每课导出本组DSL并单独保存资料原文、提示词和测试记录。导入方法与节点说明见[语言项目操作手册](../语言项目操作手册.md)。

模板不含账号凭证、API Key或知识库正文。导入后仍需配置模型与知识库。共享工作区的Editor账号可编辑其他组内容，课堂按组号操作并由教师备份。

## 四、保存与使用约定

- 公共材料保留原件；修改发生在小组副本中。
- 视觉原图、模型和工程分别保存；展品文本供语言项目使用，不作为视觉训练图片。
- 视觉项目用V1/V2比较改动；语言项目第6、7、8课分别保存V1/V2/V3。文件名加项目名称与组号，避免混淆。
- 课堂结果记录真实输入与输出，不把示例回答或虚构展品数字写成本组实测结果。
- 第2～10课可投屏操作手册和任务卡，按分课教学设计组织课堂。服务器部署步骤由教师或技术负责人完成，不作为学生任务。
