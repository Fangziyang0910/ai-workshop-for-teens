# Mind+课堂起始工程

[项目首页](../../../README.md) · [课堂配套材料](../README.md) · [视觉项目操作手册](../../视觉项目操作手册.md)

使用Windows版Mind+ V1.8.1 RC3.0，在“文件—打开”中选择`.mp`文件。工程使用实时模式。每个工程旁的`.json`是同一工程的可读源文件，供版本比较和维护，不在Mind+中直接打开。

| 工程 | 用途 | 设备 |
|---|---|---|
| [第2课_三类图像分类.mp](第2课_三类图像分类.mp) | 第2课起用于采样、训练、屏幕显示和模型保存 | 电脑、摄像头 |
| [第3课_灯阵连接检查.mp](第3课_灯阵连接检查.mp) | 单独检查连接，手动显示左右箭头与等待横线 | 电脑、micro:bit V2 |
| [第3至5课_识别与灯阵联动.mp](第3至5课_识别与灯阵联动.mp) | 将三个类别接入灯阵，继续测试和制作 | 电脑、摄像头、micro:bit V2 |

这些工程预置程序，不含实物照片或已训练模型。先按下面顺序完成一次采样，再保存本校的示范模型。摄像头位置、物品和背景均应与课堂条件相符。

## 一、第一次运行分类工程

1. 将工程复制到本组目录，用Mind+打开。确认扩展中显示“机器学习（ML5）”，当前为实时模式。
2. 插入摄像头，关闭Windows相机等占用程序。点一次绿旗，等摄像头打开和初始化完成。
3. 先做小规模演练：摆放胶棒，按数字`1`一次，再变换位置。拍10次；橡皮按`2`，空背景按`3`，各拍10次。按一次只加入一张。不要长按。
4. 按`T`训练。等待训练结束，观察屏幕上的“当前标签”。训练结束后程序自动开始识别。
5. 按`P`暂停，按`S`继续。训练或加载成功前不要按`S`。
6. 点击`V`脚本中保存模型积木的设置按钮，选择本组“模型”目录；按`V`保存。确认目录内实际生成`.json`模型文件。
7. 用“另存为”保存自己的`.mp`工程。直接摄像头采样不会留下独立原图，正式第2课改用下节方法。

## 二、使用可保存原图的文件夹采样

1. 按`P`，关闭Mind+摄像头。用Windows相机拍摄三类图片，每类约20张，复制到`原图/glue`、`原图/eraser`、`原图/background`。
2. 关闭相机，回到Mind+。先保存旧模型；需要重新建模时关闭并重新打开工程，再点绿旗。
3. 找到`F`脚本，点击三个文件夹选择按钮，分别指定上述目录。标签保持不变。
4. 按`F`导入一次。核对每次导入反馈，三类都成功后再按`T`。重复按`F`会重复加入样本。
5. 按`V`保存模型，另存工程，并保留原图。V2改进时使用新文件名。

本版本单次读取一个文件夹最多取50张。基础任务每类20张，三类共60张。扩展名统一使用小写`.jpg`、`.jpeg`或`.png`。不要在同一目录混入不同类别。

## 三、恢复已有模型

1. 打开已保存工程，点绿旗，等待初始化完成。
2. 点击`L`脚本中加载模型积木的设置按钮，选择保存的模型`.json`。
3. 按`L`加载。确认没有路径或格式错误，再按`S`开始识别。
4. 加载后不按`T`，不重复点绿旗。要补采样并重新训练时，从原图重新建立一个新版本。

## 四、检查开发板并接入识别

1. 打开“灯阵连接检查”工程，用数据线连接micro:bit V2。选择正确串口，按Mind+提示写入实时通信固件。
2. 点绿旗显示横线。数字`1`显示左箭头，`2`显示右箭头，`3`和`P`显示横线。
3. 三种图案都能显示后，打开“识别与灯阵联动”工程。加载已有分类模型，按`S`。
4. 依次放入胶棒、橡皮和空背景，核对屏幕标签与灯阵。按`P`后应立即恢复横线。

联动工程中，数字`1`、`2`、`3`用于采样，与连接检查工程的用途不同。课前在黑板或操作卡上写明当前工程和按键。

## 五、课堂发放与验证

工程结构、积木名称、字段和模型格式按该版安装包核对。Windows界面、摄像头和开发板的连通检查由教师按上述步骤完成，完成后保留本校通过检查的工程与模型。不要把尚未选择的文件路径直接发给学生当成已配置工程。

第1课直接使用[离线手写数字识别](../../../01_AI侦探/授课课件/课堂演示/手写数字识别.html)，无需本工程或预先训练文具模型。第2课起统一使用`glue`、`eraser`、`background`三个类别。
