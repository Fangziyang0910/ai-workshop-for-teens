# 第4课 测试并改进识别效果

[项目首页](../README.md) · [课程资料目录](../00_课程大纲与资料/README.md) · [上一课：用灯阵显示识别结果](../03_用灯阵显示识别结果/README.md) · [下一课：完成物品识别提示器](../05_完成物品识别提示器/README.md)

## 一、本课定位

视觉项目第3课：用同一组条件比较改动前后的表现。沿用第3课的装置。

面向零基础初中生；每班约30人、8组，每组3～4人；每次90～120分钟。

| 项目 | 本课安排 |
|---|---|
| 核心问题 | 错误从哪里来，哪一项改动有帮助？ |
| 重点讲解 | 控制测试条件、区分分类错误与显示错误、根据记录判断改进。 |
| 学生实操 | 完成两轮各18次测试，保留视觉V1和V2，只实施一项主要改动。 |

## 三、课前准备

**硬件与物品：**每组带齐上一课的电脑、摄像头、开发板、数据线和物品；另备背景纸、位置标记及纸板固定材料。

**软件与文件：**Mind+及本组联动工程。先保存视觉V1，再复制为V2。

1. 用原条件、只换背景、只改位置三种条件布置测试区；每种条件三类各测2次，共18次。
2. 保留可恢复的V1。补充训练图片另拍，不直接使用测试图片。
3. 准备背景与类别绑定的例子，让学生看到模型可能利用了物品以外的线索。

## 四、课堂安排

按以下顺序组织课堂；各环节时长以本课完整教学设计为准。

1. 请另一组操作，记录一个具体问题，并提出可检查的猜想。
2. 完成第一轮18次测试，分别记录真实类别、模型标签和灯阵。
3. 选择补充训练样本或改变结构中的一项主要改动，说明理由。
4. 保存V2，在相同条件下完成第二轮18次测试。
5. 比较消失、保留和新增的错误，填写改进卡；没有提高时保留真实结果。

## 五、成果检查

- [ ] V1、V2及两轮测试均可追溯，分类与显示错误分开记录。
- [ ] 能说明改变了什么、保持了什么，以及结果在哪些条件下成立。
- [ ] 评价依据是记录和解释，不要求V2一定优于V1。

## 六、课后衔接

**课后任务：**每人寻找一个没有测过的条件，小组选一项继续检查。可比较补充重复画面与新角度的效果。

**下次课准备：**两版文件、18次测试表、改进卡和当前装置。

课后基础任务约30～60分钟。没有家庭电脑时，先整理材料与记录，再到学校开放机房操作。
