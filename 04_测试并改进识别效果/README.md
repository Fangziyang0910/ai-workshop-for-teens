# 第4课 测试并改进识别效果

本课面向零基础初中生，每班约30人，分为8组，课时为90～120分钟。

## 教学目标

学生能够提出装置失效的一个可能原因，设计可比较的测试，选择补数据或改结构，并依据前后结果说明判断。学生先观察错误，再提出原因、实施改动，并通过再次测试检查判断。

## 成果与评价

提交V1/V2、两轮测试表和一张改进卡。教师评价问题是否具体、改动是否有理由、比较是否公平、解释是否符合记录。即使识别效果没有提高，只要学生能根据结果排除一种猜想，也应认可其学习成果。
