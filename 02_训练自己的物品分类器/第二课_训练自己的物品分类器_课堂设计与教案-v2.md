## 一、本课在讲什么

**一句话：**第一课用了别人教好的AI；这节课，学生自己当老师，教电脑分清两种文具和空桌面。

| 项目 | 本课安排 |
|---|---|
| 核心问题 | 怎样教电脑分清我们选的东西？ |
| 学生要懂的四件事 | ①分几类、叫什么，由人决定；②电脑靠我们给的例子学，例子要多样、要干净；③电脑把画面变成特点数字，找“最近的邻居”投票来判断，可能出错；④它只会在我们给的几类里选，放进没教过的东西，也会硬选一个 |
| 学生要做的事 | 打开软件和项目；每人复原1块积木，全组给两类起名字；调好摄像头；四个岗位配合采样；训练；先猜再考；保存 |
| 不讲的内容 | 编程语法、神经网络结构、准确率计算。KNN页右侧的距离公式只供高年级了解，不要求掌握 |
| 达标标准 | 程序复原并能运行；三类都能显示判断结果；四个岗位都有人负责、每人装过一块零件；工程和模型都保存在本组文件夹；能说出“它只会在几类里选” |

不以识别得准不准作为达标条件。认错了但说得出“哪种情况容易错”的小组，同样完成了本课目标。

## 二、设计决定

1. **开场从生活走到本单元作品。**先说生活里会认东西的机器（识花、超市称水果、分垃圾、相册找猫），再问它们怎样学会，接上第一课的数字识别；然后介绍本单元要做的“桌面物品识别提示器”和第2～5课的路线；最后老师现场演示，放一支没教过的笔，留下“它为什么没说我不认识”的悬念，到收尾时用特点地图揭晓。
2. **四站结构：修、懂、教、考。**每站开头有分隔页，学生知道自己走到了哪里。
3. **项目不是现成的。**学生版工程掉了4块积木：开启摄像头、1号键和2号键的“加入类别”、开始分类训练。老师先讲每个按键的作用，再通过提问引导学生找回位置。3号键保持完整，作为学生照着拼的样板。四块零件正好四个人每人装一块。
4. **标签用中文，由小组决定。**第三类固定为“空背景”，另外两类在复原1号、2号积木后由小组定名。这一步本身就在讲“类别由人决定”。
5. **先懂再教：KNN放在点绿旗之前。**用文具贯穿：“猜猜我是谁”让学生体会“靠特点、靠见过的例子”认东西；再把文具变成“长度、宽度”两个分数，放到特点地图上；新来的点找最近的3个邻居投票；然后用一页正式介绍K近邻算法的四个步骤，右侧“多知道一点”给出距离公式、K取奇数、Mind+先用预训练模型提取特征等，体现一点技术含量。最后落到“按1、2、3＝往地图上放点，按T＝记好这些点”和三条规矩，学生带着理由去采样。地图中的分数是编的，课件构建时校验过三处投票结果与讲稿一致。
6. **岗位固定，不轮换。**摄像头员、摆放员、按键员、测试员各管一件事，四年级学生不用记换岗规则。测试员在采样时数数，训练后主持考试，这样每个人都有“高光时刻”。第3轮拍空背景时摆放员没事做，可以和按键员换一下。
7. **按键采样，不用文件夹导入。**按`1`、`2`、`3`直接把摄像头画面加入类别，学生立刻看到效果，四年级也能完成。代价是不留下独立照片；下节课用保存的模型继续，需要重新训练时再按键采样。两份工程都已删除`F`文件夹导入脚本，避免误按。
8. **每类10个例子。**够跑通流程，省下的时间用于考试和讨论。补例子改为快组的挑战卡。
9. **关闭后重新打开的检查放到第三课开头。**第三课一上来就要用`L`读取模型，那一步就是检查。本课只要求保存到位。

## 三、课前准备

### （一）老师先在自己的电脑上验证两份工程

两份工程由原课程的`第2课_三类图像分类`改写而成，只改了标签和默认文字、删掉了`F`脚本、拆下了4块积木，其余积木没有改动。它们还**没有在Mind+中打开过**。请先完成以下检查：

1. 打开教师版，完整走一遍：绿旗 → 按1、2、3各采几次 → `T` → 识别 → `P` → `V`保存 → 另存项目。
2. 打开学生版，确认4块积木在脚本区下方，并且能拖回原位；复原后结果与教师版一致。
3. 把需要的界面截下来，替换课件中的虚线截图框，并补进学生教程。
4. 把第九节的实测结果填好。

**任何一份打不开时，**用原工程手工制作：打开`第2课_三类图像分类.mp`，把1、2、3键的标签改为`物品1`、`物品2`、`空背景`，删除`F`脚本，另存为教师版；再把上述4块积木拖到脚本区下方，另存为学生版。

### （二）每台学生电脑（10台，最好由助教在课前完成）

1. 安装好Mind+和学生包。在桌面放`第2课_学生版_待复原.mp`，并建好本组文件夹，如`第01组`。如果机房有还原系统，文件夹要放在不会被清空的位置。
2. 插好摄像头，装在支架上朝下，对准用胶带固定好的白色背景纸。用Windows相机确认有画面后，**关闭相机**。
3. 桌上贴一张按键卡：绿旗只点一次，`1`、`2`、`3`给例子，`T`训练，`P`暂停，`V`保存。

### （三）教师演示台

- 电脑接投影，摄像头画面能投给全班看。
- 打开教师版，用自己的两种文具训练好一个演示模型并保存，用于第5页。第5页还要准备一支没教过的笔。
- 课件中的积木示意图、特点地图都已画好；只有虚线框的截图位置需要实测后替换，第31页还要补拍转动对焦环的照片。

### （四）物品与打印

- 学生按第一课的预告自带文具。老师另备3～4套备用，如笔盒、橡皮、卷笔刀、胶带。**尽量每组每种文具有两件不同款式**，考试时“换一件”才有意义。
- 学生图文教程每组1份，另备2份；建议A4双面，彩色打印截图。
- 可选：“AI训练师”贴纸或印章，用于第42页。

### （五）人员

10组同时操作，**建议至少配1名助教，最好2名**，每人负责5组巡视。复原积木和采样是最需要巡视的两个环节。没有助教时，复原积木环节由老师在投影上一块一块带着做，所有组做完一块再做下一块。

## 四、75分钟流程

| 部分 | 讲稿页 | 时间 | 学生做什么 | 完成标志 |
|---|---|---:|---|---|
| 引入 | 1–6 | 0–10 | 说说见过的识别功能；了解本单元作品；看老师演示并先猜结果；分好岗位 | 岗位写进教程第0步 |
| 第1站 修 | 7–17 | 10–26 | 打开Mind+、接摄像头、打开学生版；认识按键；每人装回一块零件；起好两类名字 | 零件区空了，名字已改好 |
| 第2站 懂 | 18–28 | 26–36 | 猜文具；看特点地图；找邻居投票；认识KNN；记住三条规矩 | 能说出“找最近的邻居投票” |
| 第3站 教 | 29–34 | 36–52 | 点绿旗，摄像头员调焦距；四个岗位配合，三类各采10次 | 画面清楚；三类计数都满10次 |
| 第4站 考 | 35–40 | 52–68 | 按`T`；测试员主持先猜再考6次；讨论；`P`、`V`、另存项目 | 考试记录写满；文件夹里有两个文件 |
| 收尾 | 41–43 | 68–75 | 解释开场的笔；一句话介绍本组AI；预告下节课 | 能说出“它只会在几类里选” |

**70分钟：**第19～21页只用两条线索；第28页只讲前两条规矩；第42页请两组发言。

**80分钟：**第38页后发放第39页挑战卡；第42页请四到五组发言。

**第1站最容易超时。**到第26分钟还没修好的组，直接换用教师版，改好名字后继续，不让一组卡住全班。第2站只听不操作，没修好的组可以利用这段时间由助教帮忙收尾。

## 五、组内岗位

| 岗位 | 修程序时 | 采样时 | 考试时 |
|---|---|---|---|
| 摄像头员 | 插摄像头；装零件① | 调好焦距和方向；盯着画面，画面干净才喊“拍” | 看画面，提醒手拿开 |
| 摆放员 | 装零件②（1号键） | 摆放文具，每次挪一挪，放好后把手拿开 | 帮测试员递文具 |
| 按键员 | 装零件③（2号键） | 听到“拍”只按一次对应的数字键 | 训练时按`T`，保存时按`P`、`V` |
| 测试员 | 装零件④（T键） | 画“正”字，数够10次喊“停” | 摆考题，组织全组先猜，记录结果 |

第3轮拍空背景时，摆放员不用摆东西，可以和按键员换一下，让每人都按过键。

## 六、学生容易有的误解

| 误解 | 怎样纠正 |
|---|---|
| “电脑认识橡皮了” | 它只是找到画面最像的邻居。放进笔，它也会选一个 |
| “例子越多越好，一直按就行” | 一模一样的例子再多也没用，要不同位置、方向、款式 |
| “认错了就是电脑坏了” | 多半是例子没教到这种情况，地图上那里没有它的邻居；补例子往往有用 |
| “手在画面里没关系” | 手也会被打进特点分数里 |
| “再点一下绿旗就好了” | 绿旗会让它忘掉学过的东西。出问题先举手 |
| “电脑真的在量文具的长和宽” | 长度、宽度是比喻。真实的特点数字有很多个，由预训练模型从图片里算出来 |

## 七、常见状况与第一处理

| 状况 | 先做什么 |
|---|---|
| 积木拖不上去，或拖错了位置 | 对照第17页的完整截图，把积木拖出来重放；乱了就换教师版 |
| 点绿旗后没有摄像头画面 | 检查零件①是否装好；关闭Windows相机；摄像头重新插拔 |
| 按数字键没反应，或数字被打进积木 | 先点舞台空白处；检查零件②③是否装好 |
| 按`T`后一直不显示判断结果 | 检查零件④是否装好；训练中不要再按键，等一会儿 |
| 不管放什么都显示同一类 | 检查1号、2号名字是否改过、三类是否都采了；必要时重新开始采样 |
| 学生误点了绿旗或关掉了软件 | 没保存就由助教判断：重新采样，或改用老师的演示模型完成考试环节 |
| 判断结果一直跳 | 把物品放稳、手拿开；仍然跳就记下来，第四课会处理 |

## 八、对后续课的影响

- 第三课的联动工程原来按`glue`、`eraser`、`background`判断显示哪个图案。改用中文自定义名字后，第三课要把判断积木里的文字改成各组的名字。请负责第三课的老师提前调整工程和讲法。
- 第三课开始时，各组打开本课另存的项目，用`L`读取模型，这一步同时检查本课的保存是否成功。
- 本课不保存独立照片。第四课需要补充训练时，可以读取模型后补例子，或重新按键采样。
- 第三课可以沿用本课的四个岗位，学生不用重新分工。
