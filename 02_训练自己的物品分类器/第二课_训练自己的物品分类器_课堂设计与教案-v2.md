## 一、教学目标与要求

第一课使用了别人训练好的模型；本课由学生自己采集样本、训练分类器，让电脑区分两种文具和空桌面。

| 项目 | 本课安排 |
|---|---|
| 核心问题 | 怎样训练一个分类器，分清我们选的东西？ |
| 学生要懂的四件事 | ①分几类、每类叫什么，由人决定；②分类器靠采集的样本训练，样本要多样、干净；③程序把画面变成特征数字，找“最近的邻居”投票得出结果，可能出错；④它只会在设定的类别里选，放进没训练过的物品也会归入其中一类 |
| 学生要做的事 | 打开软件和项目；四人各装回1块积木，设定两个类别名称；调好摄像头，配合采集三类样本；训练分类器，先猜再测；保存模型和工程 |
| 不讲的内容 | 编程语法、神经网络结构、准确率计算；KNN距离公式仅作延伸，不要求掌握 |
| 达标标准 | 程序装好并能运行；三类都能显示识别结果；每人承担一个岗位并装回1块积木；工程和模型保存在本组文件夹；能说出“它只会在设定的几类里选”。不以识别准确率作为达标条件 |

## 二、教学设计要点

1. **按训练流程推进课堂**。全课按“准备程序 → 采集样本 → 训练 → 测试 → 保存”五步展开；采样前用10分钟讲清特征空间与K近邻（KNN）投票，让学生理解采样规则后再动手。
2. **首尾呼应未知物品问题**。开场演示时放入一支未训练过的笔，留下“为什么它没说我不认识”的悬念；收尾时回到特征空间，由学生用“找最近邻居”自行解释。
3. **集中四处关键互动**。提问集中在四处主线节点：第5页猜未知的笔、第22页判断边界点B、第33页组内先猜再测、第37页解释那支笔；其余步骤由教师直接示范说明，保证10组同步推进。
4. **装回积木与自定类别结合**。学生版拆下4块关键积木（开启摄像头、1号和2号加入类别、开始分类训练），以完整的3号键（空背景）为样板，四人每人装回一块，并由小组商定另外两类文具的中文名称。
5. **按键实时采样，每类10次**。按`1`、`2`、`3`直接将当前画面加入对应类别，省出时间用于预测、测试与错例分析；补充样本留作快组的挑战卡。

## 三、课前准备

### （一）学生电脑（10台）

1. 安装好Mind+（含ML5扩展）。桌面放`第2课_学生版_待复原.mp`，并建好本组文件夹（如`第01组`，避开机房还原清空目录）。
2. 插好摄像头并固定在支架上朝下，对准贴好的白色背景纸。确认画面正常后**关闭系统相机**，避免占用摄像头。
3. 桌贴按键提示：绿旗只点一次，`1`、`2`、`3`加入样本，`T`训练，`P`暂停，`V`保存。

### （二）教师演示台

- 电脑接投影，确保摄像头弹窗与Mind+舞台可同时投屏。
- 打开`第2课_教师版_完整.mp`，课前用两种文具和空桌面训练并保存好演示模型，另备一支未训练过的笔（第5页演示用）；课前跑通一遍学生版装积木与保存流程。

### （三）物品与材料

- 学生自带两种文具；教师另备3～4套备用文具（笔盒、橡皮、卷笔刀、胶带等）。每组同一种文具尽量备两件不同款式，便于测试“换一件”。
- 学生图文教程每组1份，另备2份；可选准备第38页用的贴纸或印章。

### （四）巡视分工

建议配1～2名助教分区巡视，重点看装积木和采样两个环节。无助教时，装积木环节由教师投屏逐块带做，全班装完一块再做下一块。

## 四、75分钟流程

| 部分 | 讲稿页 | 时间 | 学生做什么 | 完成标志 |
|---|---|---:|---|---|
| 引入 | 1–6 | 0–10 | 了解本单元作品；看老师演示，猜那支笔；分好岗位 | 岗位写进教程第0步 |
| 准备程序 | 7–16 | 10–26 | 打开Mind+、接摄像头、打开学生版；认识按键；每人装回一块积木；设置两个类别名称 | 4块积木已装好，类别名称已改好 |
| 采样前：分类器怎样识别 | 17–26 | 26–36 | 听讲：特征、特征空间、找邻居投票、KNN、三条采样规则 | 能说出“找最近的邻居投票” |
| 采集样本 | 27–31 | 36–51 | 点绿旗，摄像头员调焦距；四个岗位配合，三类各采10次 | 画面清楚；三类计数都满10次 |
| 训练和测试 | 32–35 | 51–65 | 按`T`；测试员主持先猜再测6次；找出认错的摆法 | 测试记录写满 |
| 保存 | 36 | 65–68 | 按`P`、`V`保存模型，另存项目 | 文件夹里有两个文件 |
| 收尾 | 37–39 | 68–75 | 解释开场的笔；一句话介绍本组分类器；了解下节课任务 | 能说出“它只会在几类里选” |

- **70分钟**：第17～18页只用两条线索；第26页只讲前两条规则；第38页请两组发言。
- **80分钟**：第34页后发放第35页挑战卡；第38页请三到四组发言。
- **超时处理**：到第26分钟仍未装好积木的小组，直接换用教师版、改好类别名称后继续，或由助教在原理讲解期间协助收尾。

## 五、组内岗位

| 岗位 | 准备程序时 | 采样时 | 测试与保存时 |
|---|---|---|---|
| 摄像头员 | 插摄像头；装积木① | 调好焦距和方向；盯着画面，画面干净才喊“拍” | 看画面，提醒手拿开 |
| 摆放员 | 装积木②（1号键） | 摆放文具，每次挪一挪，放好后把手拿开 | 递测试文具 |
| 按键员 | 装积木③（2号键） | 听到“拍”只按一次对应数字键 | 训练按`T`，保存按`P`、`V` |
| 测试员 | 装积木④（T键） | 画“正”字，数够10次喊“停” | 摆测试物品，组织全组先猜，记录结果 |

第3轮拍空背景时，摆放员可与按键员互换，让每人都体验按键采样。

## 六、学生常见误解

| 误解 | 引导方式 |
|---|---|
| “电脑认识橡皮了” | 它只是找到画面最接近的邻居；放进没学过的笔，它也会选出其中一类 |
| “样本越多越好，一直按就行” | 重复拍同一画面没有用，需要不同位置、方向和款式 |
| “认错了就是电脑坏了” | 多半是缺少这种摆法的样本，特征空间里附近没有同类邻居；补样本往往有用 |
| “手在画面里没关系” | 手也会一起被算进画面特征 |
| “再点一下绿旗就好了” | 绿旗会重新初始化分类器并清空已采样本；遇到问题先举手 |
| “电脑真的在量文具的长和宽” | 长度、宽度只是教学举例；实际由预训练模型从图片里算出许多特征数字 |

## 七、常见状况与处理

| 状况 | 处理方法 |
|---|---|
| 积木拖不上去，或拖错了位置 | 对照第16页完整截图重放；顺序乱了直接换教师版 |
| 点绿旗后没有摄像头画面 | 检查积木①是否装好；关闭系统相机；重新插拔摄像头 |
| 按数字键没反应，或数字被打进积木 | 切换英文输入法，先点舞台空白处；检查积木②③是否装好 |
| 按`T`后一直不显示识别结果 | 检查积木④是否装好；训练时不要继续按键，稍等片刻 |
| 不管放什么都显示同一类 | 检查1号、2号名称是否重名，三类是否都采了样本；必要时重新采样 |
| 误点绿旗或关掉了软件 | 未保存时由助教判断重新采样，或改用演示模型完成测试 |
| 识别结果一直跳 | 把物品放稳、手拿开；仍跳动则如实记录，留到第四课处理 |

## 八、课后与下节课衔接

- 保留各组文件夹中的工程文件（`.mp`）和模型文件（`.json`），提醒学生下节课继续带今天使用的两种文具。
- 第三课沿用本课的四个岗位：开头打开本组工程，用`L`读取本课保存的模型，并将条件判断积木中的类别文字改为本组设定的名称。
- 第四课补充改进时，可在读取模型后按键补采样本再按`T`重新训练，或重新采样训练。
