# 第二课课件视觉设计 spec（三方向初稿的共同输入）

**产品**：AI 创想工坊·第二课《教 AI 认识身边的物品》授课课件，39 页，75 分钟，课堂投影。最终交付为可编辑 PPTX（教师现场改动），设计稿用 HTML 做方向验证。

**受众与场景**：四至七年级学生，约 40 人，教室后排也要看清；教师边讲边带操作，约一半页面是 Mind+ 实操步骤（配真实截图），另一半是概念页（特征、特征空间、K 近邻投票）。

**核心信息**：训练分类器分五步（准备程序→采集样本→训练→测试→保存），四人四个岗位；KNN 的本质是“找最近的邻居投票”；分类器只会在训练过的类别里选。

**情感基调**：清楚、有秩序、让十岁孩子觉得“我能做到”，同时让老师和学校觉得专业。不幼稚，不堆装饰。

**输出格式**：16:9，1920×1080 设计，最终 PPTX 13.333×7.5 英寸。正文不小于 20pt，标题 36pt 以上。

**已知约束**：用华南理工大学标志（白/蓝版本，本地已有）；步骤色标对应五步；Mind+ 截图是橙色界面，需要与整体配色相容；教师电脑字体以微软雅黑为准，自定义字体需单独安装或回退。

**图片需求**：Mind+ 操作截图用真实截图（17 张，已有）；概念示意图用矢量或 Codex 生图。已验证 Codex 生图可用：封面“摄像头朝下拍桌面”插图（`img/A_cover.png`）。

**视觉母题（form 来自内容）**：分类器的“点云与邻居”——每个样本是一个点，邻居用虚线相连，票数用圆点或图标计数。三个方向都把这个母题放进封面或版式。

**三个方向的来源**
- A · 轮盘：`date +%S`=48，48 % 20 + 1 = 9，PPT 风格库第 9 号 Bento 便当格。
- B · 现实参照：Duolingo 的学习界面语法（Johnson Banks 2019 品牌；厚底按钮、进度条、反馈条）。只迁移版式语法，不使用其标志和角色。
- C · 最佳设计师：Otto Neurath / Gerd Arntz 的 Isotype 图示法，“一个图标=一个单位”，用于向大众解释数据。
