# 第2课 训练自己的物品分类器

[项目首页](../README.md) · [课程资料目录](../00_课程大纲与资料/README.md) · [上一课：AI侦探](../01_AI侦探/README.md) · [下一课：用灯阵显示识别结果](../03_用灯阵显示识别结果/README.md)

## 一、本课定位

视觉项目第1课：由学生自己采集样本、训练分类器，让电脑区分桌上的两种文具和空桌面；下节课把识别结果接到开发板灯阵。

面向四至七年级、零编程基础的学生；全班约40人，4人一组共10组，每组一台电脑和一个摄像头，课长75分钟。

| 项目 | 本课安排 |
|---|---|
| 核心问题 | 怎样训练一个分类器，分清我们选的东西？ |
| 重点讲解 | 类别、样本、标签、特征、特征空间与K近邻（KNN）投票。用特征数字和“找最近邻居”讲清采样规则与未知物品误判。 |
| 学生实操 | 装回4块关键积木并自定义两类文具名称；对准背景纸采集三类样本（每类10次）；按`T`训练、先猜再测，保存模型和工程。 |

## 三、课前准备

1. **学生电脑（10台）**：安装Mind+ V1.8.1 RC3.0（含ML5扩展）；桌面放置`第2课_学生版_待复原.mp`，建好本组文件夹（如`第01组`，避开机房还原清空目录）。
2. **摄像头与背景纸**：插好USB摄像头并固定在支架上朝下，对准白色背景纸；确认画面正常后**关闭系统相机**，避免占用摄像头。
3. **教师演示台**：连接投影，确保摄像头弹窗与Mind+舞台可同时投屏；用`第2课_教师版_完整.mp`提前训练并保存演示模型，另备一支未训练过的笔（用于第5页开场演示）；课前实机跑通一遍装积木与保存流程。
4. **物品与打印材料**：学生自带两种文具，教师另备3～4套备用文具（笔盒、橡皮、卷笔刀、胶带等，每类尽量备两件不同款式）；按组数打印`第二课_图像分类器_学生操作手册.docx`（10份＋2份备用）。

## 四、课堂流程（75分钟）

1. **引入（0–10分钟）**：看本单元作品；演示分类器并放入未训练过的笔留下悬念；4人分好岗位（摄像头员、摆放员、按键员、测试员）。
2. **准备程序（10–26分钟）**：打开Mind+与`第2课_学生版_待复原.mp`，确认“实时模式”；4人各装回1块积木（`开启 摄像头`、1号与2号`KNN将摄像头画面分类为`、`KNN开始分类训练`），将`物品1`、`物品2`改成中文文具名。
3. **采样前原理（26–36分钟）**：讲清特征、特征空间、找邻居投票（KNN）与三条采样规则（样本要多样、背景要一样、手要拿开）。
4. **采集样本（36–51分钟）**：点一次绿旗（仅点一次），调好镜头焦距与背景纸；四人按“放好 → 手拿开 → 看一看 → 按一下 → 挪一挪”配合，按`1`、`2`、`3`三类各采10次。
5. **训练与测试（51–65分钟）**：按`T`训练；测试员组织先猜再测6次（含1次未训练过的物品），完成记录并思考“为什么会说出已有类别”。
6. **保存与收尾（65–75分钟）**：按`P`暂停，按`V`在弹窗中选本组文件夹保存模型（`.json`），再通过“项目 → 另存项目”保存`第XX组_第2课.mp`；用“找最近邻居”解释开场的笔，一句话总结本组分类器。

## 五、成果检查

- [ ] 程序装好并能运行，三类画面均能正常识别。
- [ ] 四名成员各自承担一个岗位并装回1块积木。
- [ ] 能用自己的话说出“它只会在设定的几类里选，所以没学过的东西也会被归到其中一类”。
- [ ] 本组文件夹内同时保存了`.mp`项目文件与`.json`模型文件。
