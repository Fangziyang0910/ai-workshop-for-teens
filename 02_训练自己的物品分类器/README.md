# 第2课 训练自己的物品分类器

本课面向零基础初中生，每班约30人，分为8组，课时为90～120分钟。

## 教学目标

学生能够把“做一个文具归位提示器”转化为两类物品与背景的识别任务，轮流采集样本、建立分类器并保存。重点是理解：类别由人确定，模型根据样本判断新的图片属于哪一类。

## 成果与评价

小组提交60张左右的分类原图、模型、工程和类别说明。每名学生至少完成一轮采样或导入，并能指出标签与预测的区别。达标依据是采样、训练、识别和保存步骤完整、文件能恢复、能解释适用范围。评价不设统一的高准确率要求。
