# 第2课 训练自己的物品分类器

[项目首页](../README.md) · [课程资料目录](../00_课程大纲与资料/README.md) · [上一课：AI侦探](../01_AI侦探/README.md) · [下一课：用灯阵显示识别结果](../03_用灯阵显示识别结果/README.md)

## 一、本课定位

视觉项目第1课：确定类别，建立分类器。下一课把识别结果接到开发板灯阵。

面向零基础初中生；每班约30人、8组，每组3～4人；每次90～120分钟。

| 项目 | 本课安排 |
|---|---|
| 核心问题 | 怎样让电脑区分我们选定的物品？ |
| 重点讲解 | 类别、样本、标签、训练与预测。学生使用已有模型提取图像特征，再建立自己的小分类器。 |
| 学生实操 | 拍摄并整理三类图片，训练分类器，用新输入测试，再保存和恢复。 |

## 三、课前准备

**硬件与物品：**每组一台Windows电脑、一只C270摄像头、胶棒和橡皮各两件、两张背景纸、文件保存介质。本课不连接开发板。

**软件与文件：**Mind+实时模式及ML5扩展。安装包从本地资源目录取得，统一版本后发放工程。

1. 在每组电脑检查相机权限，关闭其他占用摄像头的软件。建立不会被机房还原系统清除的保存目录。
2. 准备一次正确识别和一次误判的演示；完整做一次关闭软件后恢复模型。
3. 统一起始标签为`glue`、`eraser`、`background`。每类约20张，共约60张；三类轮换使用相同背景。

## 四、课堂安排

按以下顺序组织课堂；各环节时长以本课完整教学设计为准。

1. 说明归位用途，写清两类物品及空背景各包含什么。
2. 轮换拍摄位置与角度，把原图放进三个对应文件夹；先检查标签和图片是否一致。
3. 初始化后导入图片，再训练并开始识别；不要重复初始化或反复导入同一批样本。
4. 换另一件同类物品或新位置测试，记录实际结果。只改变一项内容，观察变化。
5. 分别保存工程MP、模型JSON、原图和类别说明。由另一名成员重新打开并识别。

## 五、成果检查

- [ ] 三类均能输出预测；能说明未知物体也可能被分进已有类别。
- [ ] 每人至少完成一次采样或导入，并能区分标签与预测结果。
- [ ] 工程、模型、原图分别保存，另一名成员能够恢复。不以统一高准确率作为达标条件。

## 六、课后衔接

**课后任务：**恢复模型，在一种新背景下测试5次，记录真实物品和预测结果。保留课堂版本后，可另做自己的类别。

**下次课准备：**工程、模型、三类原图、5次记录，以及micro:bit V2和数据线。

课后基础任务约30～60分钟。没有家庭电脑时，先整理材料与记录，再到学校开放机房操作。
